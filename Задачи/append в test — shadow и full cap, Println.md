# append в test — shadow и full cap, Println

**Собес:** [[СимберСофт]] · ~07:59–12:18

Что выведет `fmt.Println` в `main`?

```go
package main

import "fmt"

func main() {
	arr := make([]int, 2, 2) // len=2, cap=2
	test(arr)
	fmt.Println(arr)
}

func test(arr []int) {
	arr := append(arr, 5)
}
```

## Решение

```
[0 0]
```

**Почему:**

1. `make([]int, 2, 2)` — слайс `[0 0]`, len=2, cap=2 (массив заполнен).
2. В `test` слайс передаётся **по значению** (копируется заголовок: ptr, len, cap).
3. `arr := append(arr, 5)` — не присваивание в параметр, а **новая локальная переменная** `arr` (shadowing через `:=`).
4. При append при полном cap выделяется **новый** базовый массив; локальный заголовок указывает на него и после выхода из `test` уничтожается.
5. Заголовок в `main` не менялся → len остаётся 2, элементы `[0 0]`.

**Что ловят на собесе:** путают «слайс ссылочный» с «изменения видны снаружи»; забывают про `:=` vs `=`; не связывают full cap с realloc.

**Как увидеть `[0 0 5]` снаружи:** вернуть слайс из `test` и присвоить в `main`: `arr = test(arr)` + внутри `arr = append(arr, 5)` (без shadowing).
