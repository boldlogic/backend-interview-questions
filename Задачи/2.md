
Что выведет данный код?

```go
package main

import (
    "fmt"
)

func main() {
    s := []int{1, 2, 3, 4, 5}
    mutate(s)
    fmt.Println(s)
}

func mutate(s []int) {
    s = append(s, []int{6, 7, 8, 9}...)
}
```

## Решение 

```go
// что выведет код
package main

import (
	"fmt"
)

func main() {
	s := []int{1, 2, 3, 4, 5} //len=5, cap=5
	mutate(s)
	fmt.Println(s) ///[1 2 3 4 5]
}

func mutate(s []int) {
	s = append(s, []int{6, 7, 8, 9}...)
	//выделяем новый базовый массив и никуда не возвращаем
}

```
