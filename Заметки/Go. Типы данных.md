# Go. Типы данных

Mind map: простые типы + ссылочные типы.

---

## Простые типы

### string

- **Неизменяемы**
- **Структура** (заголовок строки):
  1. Указатель на массив байтов с фактическими данными
  2. Длина строки
- **Последовательность байтов** — не требуется, чтобы байты были символами в какой-либо конкретной кодировке
- Функции Go предполагают кодировку **UTF-8** (кодовые точки Unicode)
- **UTF-8** — основная кодировка для Unicode
- `len(s)` — **длина в байтах**; символы вне ASCII могут занимать > 1 байта
- Для подстрок и кодовых точек — `strings`, `unicode/utf8`, а не срезы/индексы «в лоб»

**Три способа «длины» строки:**

| Способ | Что считает |
|--------|-------------|
| `len(s)` | байты |
| `utf8.RuneCountInString(s)` | кодовые точки Unicode |
| `[]rune(s)` | срез рун (копия для изменения по символам) |

### Целочисленные типы

#### Знаковые

| Тип | Диапазон |
|-----|----------|
| `int` | платформенный (32/64 бита) |
| `int8` | −128 … 127 |
| `int16` | −32 768 … 32 767 |
| `int32` | −2 147 483 648 … 2 147 483 647 |
| `int64` | −9 223 372 036 854 775 808 … 9 223 372 036 854 775 807 |

Если `int64` недостаточно — `big.Int` из `math/big`.

#### Беззнаковые

| Тип | Диапазон | Примечание |
|-----|----------|------------|
| `uint8` | 0 … 255 | = `byte` |
| `uint16` | 0 … 65 535 | |
| `uint32` | 0 … 4 294 967 295 | = `rune` |
| `uint64` | 0 … 18 446 744 073 709 551 615 | |
| `uint` | платформенный (32/64 бита) | |

- Ноль `int` ≠ ноль `int32`

#### `uintptr`

- Целое **без знака**
- Адреса памяти и подобные значения
- Размер зависит от архитектуры (обычно 4 или 8 байт)

#### Арифметика и побитовые операции

`+` `−` `*` `/` `%` · `<<` `>>` — побитовые сдвиги

---

### Числа с плавающей точкой

- **Вещественные:** `float32`, `float64` — **`float64` предпочтительнее** (меньше погрешность)
- **Комплексные:** `complex64` (два `float32`), `complex128` (два `float64`)

---

### bool

- Занимает **1 байт**
- Логика: `&&`, `||`, `!`
- Передаётся **по значению**

---

### byte (`uint8`)

- Синоним `uint8`, взаимозаменяемы
- Работа со строками и `[]byte`
- Значения 0 … 255
- ASCII и байты UTF-8
- Побитовые операции

---

### rune (`int32`, Unicode code point)

- 4 байта, любой символ Unicode
- Поиск, сравнение, замена отдельных символов
- Символ из строки: `[]rune(s)[i]` (или `for i, r := range s`)

## Ссылочные типы

### Срезы (slice)

- Длина **не** входит в тип (в отличие от массива)
- **Несравниваемый** тип
- Сравнение содержимого — `reflect.DeepEqual`

### Массивы (array)

- Все элементы одного указанного типа
- Сравнение: `==`, `!=`
- В Go только **одномерные**; многомерность — массив массивов
- **Размер — часть типа** `[N]T`
- Нельзя привести `[3]int` к `[5]int`

### Структуры (struct)

- Группировка связанных данных
- Тип, объявленный **внутри функции**, виден только там
- Zero value: каждое поле — zero value своего типа
- Доступ к полям: **точечная нотация**
- **Анонимные** (без имени типа):
  - маппинг внешних данных ↔ struct
  - удобны в тестах
  - сравнение без преобразования типов, если поля совпадают по именам, типам и порядку (если хотя бы один тип анонимный)
- Сравнимость зависит от полей
- Разные именованные struct-типы **не сравниваются** напрямую
  - преобразование между типами возможно, если поля совпадают по именам, типам и порядку
- Поддерживают **методы**
