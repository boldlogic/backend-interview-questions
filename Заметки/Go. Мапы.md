# Go. Мапы

Неупорядоченная коллекция уникальных пар «ключ → значение». Быстрый доступ по ключу. **Несравниваемый** тип (map нельзя сравнивать через `==`). **Не потокобезопасны** без sync.

---

## Операции

### Добавление и изменение

- `m[key] = value` — если ключ есть, перезапись; если нет — создание
- Сокращённые формы: `m[key]++`, `m[key] += n`
- При росте map runtime может **перемещать** элементы в памяти → **нельзя взять адрес** элемента map (`&m[k]`)

### Чтение

| Форма | Поведение |
|-------|-----------|
| `v := m[key]` | значение или **zero value** типа, если ключа нет |
| `v, ok := m[key]` | `ok == false`, если ключа нет (отличить «нет ключа» от zero) |

### Удаление

- `delete(m, key)` — безопасно для `nil` map и отсутствующего ключа

### Итерация

```go
for k, v := range m { ... }
```

- Порядок ключей **не гарантируется** (намеренно random в runtime)
- В цикле **можно** добавлять и удалять:
  - удалённые ключи **не** появятся в следующих итерациях
  - для **новых** ключей гарантий нет

### `len(m)`

- Количество пар в map
- **Не** доказывает, что map инициализирована (`nil` map тоже `len == 0`)

## Создание и инициализация

| Способ | `nil`? | Чтение | Запись |
|--------|--------|--------|--------|
| `var m map[K]V` | да | zero value | **panic** |
| `m := map[K]V{}` | нет | OK | OK |
| `m := make(map[K]V)` | нет | OK | OK |
| `make(map[K]V, hint)` | нет | OK | OK |

- Второй аргумент `make` — **hint** (начальная ёмкость), не лимит роста
- Заранее задать hint — снизить частоту **эвакуации** при росте

---

## Ключи и значения

### Ключи

- **Уникальны** (один ключ — одно значение)
- Тип ключа должен быть **comparable**

| Можно | Нельзя |
|-------|--------|
| `int`, `string`, `bool` | `slice`, `map`, `func` |
| `array` (если элементы comparable) | |
| `struct` (если **все** поля comparable) | |

### Значения

- Ограничений по типу **нет**

## Копирование и передача в функцию

### Поверхностное «копирование»

```go
m2 := m1
```

- Новая переменная, **та же** map под капотом — изменения видны в обеих
- Копируется ссылка на hmap, не содержимое

### Глубокое копирование

- Только вручную или `maps.Clone` (Go 1.21+)

### Аргумент функции

- Map передаётся **по значению заголовка**, но указывает на **общие данные**
- Запись `m[k] = v` внутри функции видна снаружи

## Устройство (хеш-таблица)

1. **Хеш-функция** по ключу → номер бакета (алгоритм задан runtime, пользователь не выбирает)
2. Пара ключ–значение кладётся в бакет
3. **Коллизии** — overflow-бакеты / open addressing (в новых версиях — Swiss map)
4. При высокой загрузке (~**80%**) — **эвакуация**: число бакетов растёт, данные перераспределяются
5. Hint в `make` уменьшает число realloc при известном размере

```
ключ → hash → бакет → (поиск / вставка)
```

---

## Зачем используют

- Кеширование, временные данные
- Частотный анализ, подсчёт повторений
- Словари / ассоциативные массивы
- Группировка данных
- Конфигурации (key → value)
- Дедупликация
