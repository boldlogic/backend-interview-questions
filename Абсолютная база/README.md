# Распознавание аудио

Транскрипты создаются скриптом `transcribe_all.py` (faster-whisper, модель `small`, язык `ru`).

## Запуск

```bat
run_transcribe_all.bat
```

Продолжение после остановки: скрипт пропускает файлы из `_progress.json`.
