# Адреса доставки
FR-ADDR-01 Система должна позволять авторизованному пользователю просматривать список его сохраненных адресов доставки
FR-ADDR-02 Система должна позволять авторизованному пользователю добавлять адрес доставки в свой профиль
# Заказ
**FR-ORD-01** При оформлении заказа авторизованному пользователю должен отображаться список его сохранённых адресов доставки (если они есть) с возможностью выбрать один адрес.  
**FR-ORD-02** Выбранный адрес доставки должен применяться к текущему заказу
