## Как собрать Docker-образа с Docker ID

Чтобы сделать новый образ, который можно опубликовать на своем аккаунте в Docker Hub, нужно:

1. Перейти в каталог проекта TODO-LIST, который вы создали на прошлом уроке.
    
2. У вас уже есть всё для создания Docker-образа. Никакие файлы менять не придется. Назовите образ `todo-app-repo`, а затем выполните следующую команду, находясь в корневом каталоге вашего приложения. Теперь вы создаете образ с учётом вашего Docker ID на Docker Hub:
    
```
docker build -t <ваш Docker ID>/todo-app-repo . 
```

В конце не забудьте точку через пробел. Она нужна для того, чтобы в образ добавить всё, что есть в каталоге вашего приложения.

Docker-образ создан — проверьте его, запустив из него контейнер. Контейнер должен запуститься так же, как и в прошлом уроке.

```
docker run <ваш Docker ID>/todo-app-repo 
```

Теперь остановите контейнер. Чтобы это сделать, вам понадобится **Container ID**.

Поздравляем! Вы собрали Docker-образ с вашим Docker ID, проверили его, запустив контейнер. Теперь можно отправить образ вашего приложения в Docker Hub.

## Пушим образ в Docker Hub

Выполнив предыдущие пункты, вы сделали практически всю работу: вошли в учетную запись, собрали Docker-образ с вашим Docker ID и проверили его работу. Теперь для того, чтобы запушить образ в Docker Hub, достаточно выполнить всего одну команду:

```
docker push <ваш Docker ID>/todo-app-repo 
```

При сборке образа мы не добавляли тег, чтобы не усложнять пример, поэтому сработает тег `latest`. Сейчас он вполне подходит.

Чтобы убедиться, что всё прошло в штатном режиме, перейдите в Docker Hub, в раздел Repositories. Здесь вы должны увидеть новый репозиторий. Если всё так — поздравляем! Вы создали свой новый репозиторий в Docker Hub.
