# Пайплайны

## Пайплайн - это набор последовательных шагов, на каждом из которых запускается одна или несколько задач по работе с кодом.

### Пайплайн можно запускать как автоматически, после заливки кода в репозиторий, так и вручную

### Шаги пайплайна могут выполняться как успешно, так и с ошибкой — и после выполнения это можно будет узнать

### Если из-за ошибки дальнейшие шаги невозможны, пайплайн вообще останавливается.

## Пайплайн может состоять из следующих шагов

### 1. Проверка кода на соответствие принятому стилю.

### 2. Запуск тестов.

### 3. Создание docker-контейнера с приложением.

### 4. Запуск контейнера

### Шаги и задачи в пайплайне зависят от потребностей проекта. Могут включать

- разные типы тестов

- генерацию документации

- проверку производительности

- прочее

### Пример

- 1. Компиляция исходного кода. go build

- 2. Проверка кода на соответствие стилю. go vet

- 3. Тесты

	- Юнит-тесты. go test ./...

	- Интеграционные. Запуск с зависимостями

- 4. Упаковка в докер-контейнер

- 5. Развертывание
