# CI/CD
## CI/CD - неотъемлемая часть DevOps-культуры, акцент на автоматизации, скорости и непрерывном улучшении процесса разработки.

## 1. CI - Непрерывная интеграция
### Определение
- CI - автоматизация сборки проекта из репозитория, выполнение тестов и проверка качества кода.
### Что даёт?
- автоматически собирает проект, ускоряя процесс разработки;
- позволяет всегда иметь актуальную сборку;
- контролирует качество кода.
	- можно добавить проверку кода на соответствие стилю
	- Проверка наличия логических ошибок
- позволяет на раннем этапе обнаружить проблемы в проекте за счёт запуска тестов;
## 2. CD - Непрерывная доставка
### Определение
- CD - автоматизация выпуска приложений, минимизация ошибок и возможность выпускать даже малые изменения.
### Что даёт?
- ускоряет процесс разработки за счёт автоматизации выпуска приложений;
- минимизирует ошибки выпуска приложений;
- позволяет в любой момент выпускать даже небольшие изменения.
## 3. Инструменты CI/CD
### GitLab CI/CD
- Интегрированный инструмент CI/CD в составе GitLab, который позволяет настраивать и выполнять процессы сборки и развертывания прямо в репозитории.
### Jenkins
- Один из самых популярных инструментов для практически всех составляющих CI/CD, бесплатный и с открытым исходным кодом. Имеет богатую экосистему плагинов, которые позволяют расширить его функциональность и интегрировать с другими инструментами и сервисами, такими как системы контроля версий, средства тестирования и облачные платформы.
### GitHub Actions
- Это инструмент для автоматизации рабочих процессов и CI/CD, встроенный непосредственно в GitHub. GitHub Actions позволяет настраивать сборку, тестирование и развертывание, используя файлы конфигурации YAML.
### TeamCity
- Платформа непрерывной интеграции и развертывания от JetBrains, предоставляющая возможности для настройки и автоматизации процессов сборки и развертывания.
