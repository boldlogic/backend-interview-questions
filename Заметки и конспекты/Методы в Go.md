Структуры описывают свойства объекта. Например, у персонажа игры свойствами могут быть его класс, имя, количество здоровья, защита или количество урона, который он может нанести. Но с помощью структуры нельзя описать действия объекта. Для этого используют **методы**. Методы улучшают структуру, добавляя ей дополнительное поведение.

## Чем методы отличаются от функций

Если рассматривать функции и методы как конструкции языка Go, то разницы между ними практически нет. Единственное, чем отличаются методы от функций — это способ их использования.

**Методы** — это функции, которые связаны с определенным типом данных и могут вызываться только экземпляром этого типа данных. Функции же не связаны ни с каким конкретным типом.

**Экземпляром** обычно называют некий объект определенного пользовательского типа, например структуры, который сохраняется в переменной. Далее с этим экземпляром можно работать как с переменной: вызывать для него методы, передавать в качестве аргументов в функции и так далее.

Думайте об этом так: Пользовательский тип, например структура, - это чертёж детали. А экземпляр этого пользовательского типа - деталь, выполненная по чертежу.

Перед объявлением метода нужно объявить пользовательский тип — здесь это будет структура. Так как вы создаёте игру, можно объявить структуру героя. Пусть у него будет имя и количество здоровья.

```
type Hero struct {
    Name string
    Health int
} 
```

После этого можно написать метод.
