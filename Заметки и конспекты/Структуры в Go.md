**Структура** — это пользовательский тип данных, который объединяет значения произвольных типов в одно целое. Каждое из значений имеет своё имя и называется полем. Структура, как единая сущность, может передаваться в параметрах функции, храниться в слайсе или мапе.

Определение структуры выполняется с помощью ключевого слова `type`, за которым следует имя структуры, ключевое слово `struct` и заключённый в фигурные скобки список полей с их типами.

`type StructName struct {`
    `Field1 type1`
    `Field2 type2`
    `// ...`
`}`

Вот так можно описать персонажа игры:

```
type Character struct {
    Health int   // здоровье
    Speed  int   // скорость
    Power  int   // сила
    Woman  bool  // true, если персонаж - женщина
} 
```
Так вы создадите собственный тип, который содержит нужные поля. Все характеристики персонажа хранятся в одном месте, и это упростит реализацию игры.

Плюс структур состоит ещё и в том, что в них всегда можно добавить новые поля или переставить местами существующие. Ведь трудно предусмотреть и описать все нужные свойства и параметры сразу.

Чтобы получить значение отдельного поля структуры, нужно указать имя переменной, содержащей структуру, и через точку имя нужного поля. Вот так: `имяПеременной.ИмяПоля`. Эту же запись можно использовать для присваивания значения полю структуры.

## Методы и их роль

**Методы** — это специальные функции, связанные с пользовательскими типами данных, такими как структуры. Методы вызываются для переменных определённого типа. Это помогает улучшить читаемость кода и повысить его модульность. Все методы для одного типа должны иметь уникальные имена, но, в отличии от функций, одно и то же имя метода может использоваться разными типами.

Метод объявляется путем указания имени переменной (приёмника или получателя) и её типа, к которой он относится, перед именем функции.

## Погружение в эмбеддинг

Представьте, что в игру нужно добавить нового персонажа — мага, у которого помимо всех перечисленных характеристик есть сила магии. Поэтому кроме существующих полей должно быть ещё одно — `Magic int`.

Если добавить это поле в структуру `Character`, то оно будет у всех остальных персонажей, которым это ни к чему. А если создавать новую структуру, то придётся копировать все существующие методы.

**Эмбеддинг** (англ. embedding — встраивание) даёт возможность использовать поля и методы одной структуры в другой. Чтобы в новую структуру встроить уже существующую, нужно в списке полей указать наименование типа встраиваемой структуры.

Скопировать код

GO

```
type NewStruct struct { // объявление новой структуры
    StructName          // встраивание существующей структуры
    Field1 type1
    Field2 type2
    //...
} 
```

Так можно описать мага с помощью эмбеддинга:

Скопировать код

GO

```
type Magician struct { // объявление новой структуры
    Character          // встраивание существующей структуры
    Magic      int
} 
```

# структуры в Go
**Структура** — это составной тип данных, объединяющий именованные значения различных типов. Каждое такое значение называется полем и имеет собственное имя и характерный для него тип данных. С помощью структуры пользователи могут создавать свои типы данных, содержащие нужный набор параметров. А затем объявлять переменные с этим типом данных.

Получается, что структура позволяет создать что-то вроде «ящика с ячейками», внутри которого можно хранить данные заранее определенных типов в «ячейках» с конкретными именами. При этом «ящиком», то есть структурой, можно оперировать как единым целым — передавать в аргументах функций или возвращать из функции. И можно заполнять отдельные «ячейки», заменяя в них данные в результате работы программы.

Для описания структуры используется такая конструкция:
`type StructName struct {`
    `Field1 Type1`
    `Filed2 Type2`
    `// ...`
`}`
где

- `StructName` – имя типа, который описывает указанную структуру;
- `Field1`, `Field2`, ... – имена полей в структуре;
- `Type1`, `Type2`, ... – типы данных полей в структуре.

Если структура имеет несколько полей одного и того же типа, их имена можно перечислить через запятую — так же, как описываются переменные с одинаковым типом.
```
type Room struct {
    Name          string
    // два поля Width и Length описаны в одной строке
    Width, Length int
    Things        []Thing
} 
```


---
Это определяемый программистом тип, который позволяет группировать элементы разных типов в один. Любая реальная сущность, обладающая определенным набором свойств (полей), может быть представлена в виде структуры.
