Чаще всего пользователи взаимодействуют с компьютером через графический интерфейс — GUI (англ. Graphical User Interface — графический интерфейс пользователя). В него входит всё, что вы видите на компьютере: рабочий стол, иконки, окна приложений. При помощи GUI, мышки и клавиатуры вы можете создавать файлы, копировать их, перемещать, запускать приложения. Но есть и другой способ взаимодействия с компьютером — CLI (англ. Command Line Interface — интерфейс командной строки).

Что такое CLI и когда его лучше использовать, рассказывается в этом уроке. Вы познакомитесь с командной оболочкой, Bash и узнаете, какие бывают команды и как их выполнять в том числе с помощью особых комбинации клавиш для работы с командной оболочкой.

## Терминал, консоль, командная оболочка и эмулятор терминала

Пока всё это звучит сложно, но давайте разбираться.

Первые компьютеры не поддерживали графический интерфейс GUI: картинок и иконок не было, поддерживался только текстовый формат. Для взаимодействия с компьютерами использовали специальное устройство — терминал (terminal, компьютерный терминал).

**Терминал** представлял собой физическое устройство, комбинацию дисплея и клавиатуры. С его помощью можно было вводить текстовую информацию в компьютер через клавиатуру и получать вывод от компьютера на дисплее тоже текстом. К компьютеру могло быть подключено несколько терминалов, и обычно не напрямую, а через сеть.

Терминал, который подключен к компьютеру напрямую, называют **консолью (console)**. Доступ к ней, как правило, имел ограниченный круг лиц, поскольку консоль позволяла настраивать компьютер.

Всё взаимодействие с компьютером в CLI, интерфейсах командной строки, происходит путем введения команды в определенную программу. Такие программы называются shell (от англ. — ракушка, оболочка).

**Shell, командная оболочка (шелл)** — это уже не физическое устройство, а программное обеспечение, через которое пользователь взаимодействует с ядром операционной системы, используя командную строку. Shell является командным интерпретатором, то есть обеспечивает выполнение команд.

В двух словах работу с командной оболочкой можно описать так: пользователь с клавиатуры вводит команду и нажимает `Enter`, система выполняет команду, пишет на экран результат и снова ожидает ввода следующей команды.

Существует большое количество различных командных оболочек. Вот некоторые из них:

- Bourne shell или sh — ранняя командная оболочка, которая доступна почти в любом дистрибутиве Unix.
- Bash (от англ. Bourne Again SHell, является каламбуром для «Born again» Shell, то есть «возрождённый» Shell) — усовершенствованная вариация Bourne shell, одна из наиболее популярных, о ней вы узнаете подробнее в этом уроке и будете использовать в рамках курса.
- Dash — занимает меньше места на диске, чем bash, но также имеет меньше возможностей.
- Zsh — расширенная версия Bourne Shell, имеет больше встроенных команд и возможностей (например, может предложить исправить ошибку в слове).
- Fish (от англ. friendly interactive shell — дружественная интерактивная оболочка) — удобная оболочка с множеством полезных функций, но скрипты не совместимы с /bin/sh или /bin/bash.

Терминал, как физическое устройство, сейчас уже не используется. Но программы без графического интерфейса до сих пор популярны. Чтобы с ними взаимодействовать, используют эмулятор терминала (terminal emulator) — приложение, эмулирующее работу терминала. Как и физический терминал, позволяет передавать ввод от пользователя в компьютер и вывод от компьютера на дисплей. Примеры эмуляторов терминала: GNOME Terminal, Konsole, xterm.

Сам эмулятор терминала, по сути, является GUI-приложением. И он, в свою очередь, запускает внутри себя какой-либо shell (например, Bash). Таким образом, с помощью эмулятора терминала вы можете использовать командную оболочку для работы с компьютером.

Часто эти понятия смешивают для краткости и удобства, называя эмулятор терминала консолью, терминалом, шеллом, командной строкой. Не стоит считать это за ошибку, все прекрасно понимают, что имеется в виду.

## Зачем нужен CLI?

Использование CLI вместо графического интерфейса имеет несколько преимуществ.

**Ресурсоэффективность.** GUI требует дополнительных ресурсов. Поэтому для устройств с ограниченными ресурсами (серверы, маршрутизаторы, устройства умного дома) лучше использовать CLI. А при удалённом доступе по сети передавать команды и результат текстом проще, чем изображением.

**Скорость работы.** Написать одну или несколько команд иногда быстрее, чем кликать мышкой по интерфейсу. К тому же на отрисовку интерфейса требуется время.

**Простота.** Выводить текст на консоль проще, чем сделать графический интерфейс. Поэтому у некоторых приложений его может просто не быть.

**Автоматизация.** Командная оболочка позволяет писать скрипты для автоматизации работы. Скрипт, как сценарий для решения какой-то задачи, содержит одну команду или набор из нескольких команд. Так как в командной строке пользователь работает с текстом, его всегда можно скопировать и вставить, поделиться им в соцсетях или сохранить в текстовом документе. Скрипт можно написать один раз и использовать постоянно, делиться с другими людьми, запускать по расписанию. Повторить такое с графическим интерфейсом будет очень сложно либо вовсе не получится.

## Bash

Bash – это командная оболочка и язык сценариев в семействе Unix-подобных операционных систем, к которым относится Linux. Он является улучшенной версией оригинальной оболочки Bourne Shell (sh) и стандартной командной оболочкой в большинстве систем Linux.

Bash предлагает много возможностей:

- Поддерживает множество команд для управления файлами, процессами, пользователями и другими аспектами операционной системы.
- Его можно использовать в интерактивном режиме, вводя команды непосредственно в терминал. Либо как оболочку для выполнения скриптов.
- Предоставляет язык сценариев для автоматизации задач. Поддерживает условия, циклы, функции и многое другое. Под функциями здесь понимается объединённый пользовательский фрагмент кода, доступный в рамках оболочки.
- Поддерживает автодополнение — клавиша `Tab` позволяет дописать команду.
- Сохраняет историю введённых команд для повторного использования — используются стрелки вниз/вверх для отображения предыдущих команд.
- Позволяет перенаправлять вывод и ввод команд как в файлы, так и между командами.
- Можно использовать переменные для хранения данных, а также выполнять различные операции, такие как условные выражения и циклы.
- Обратно совместим с Bourne Shell, что позволяет использовать большинство команд и сценариев, написанных для Bourne Shell.

## Использование командной оболочки

Вы уже знаете, что командная оболочка нужна для выполнения команд. Достаточно написать имя команды, нажать `Enter`, и команда выполнится. На консоли появится результат выполнения, если команда подразумевает его вывод. Взгляните на выполнение команды `pwd` (англ. Print Working Directory — напечатать рабочую директорию).

![Команда_pwd](https://code.s3.yandex.net/go/go1F/40.%D0%98%D1%81%D0%BF%D0%BE%D0%BB%D1%8C%D0%B7%D0%BE%D0%B2%D0%B0%D0%BD%D0%B8%D0%B5_%D1%82%D0%B5%D1%80%D0%BC%D0%B8%D0%BD%D0%B0%D0%BB%D0%B0.%D0%9A%D0%BE%D0%BC%D0%B0%D0%BD%D0%B4%D0%B0_pwd.png)

Как видно из названия, она выводит текущую рабочую директорию — в которой вы находитесь. Эта команда пригодится, если вы попали в командную оболочку, но не знаете, в какой директории. Попробуйте выполнить её у себя.

Для выполнения некоторых команд можно указывать дополнительные параметры и аргументы, которые при добавлении к команде изменят её поведение. Параметры указываются через `-` или `--` — в зависимости от самого параметра. Их ещё иногда называют флагами.

При передаче параметра обычно используется `-` для однобуквенных параметров (например, как `-m`), а `--` — для параметров, заданных полным именем (например, `--color`).

Чтобы лучше понять, о чём речь, посмотрите на пример: `ls -m /var`.

- `ls` — это команда, она выводит список файлов и директорий;
- `-m` — параметр, который говорит команде, что выводить список нужно через запятую;
- `/var` — аргумент команды, в качестве аргумента команда `ls` принимает путь к директории, содержимое которой нужно вывести.

Взгляните на результат работы команды `ls -m /var` и `ls /var`. Без аргумента `-m` команда ведёт себя иначе.

Скопировать код

BASH

```
# ls -m /var
backups, cache, lib, local, lock, log, mail, opt, run, spool, tmp
# ls /var
backups  cache  lib  local  lock  log  mail  opt  run  spool  tmp 
```

Некоторым параметрам можно задавать значения. Например, у команды `ls` есть параметр `--color`, который задаёт цвет текста на консоли. Ему можно присвоить значение `yes`, написав `--color=yes`. После этого команда будет раскрашивать в выводе файлы и папки в зависимости от их типов. Выглядит это так:

![](https://code.s3.yandex.net/go/go1F/40.%D0%98%D1%81%D0%BF%D0%BE%D0%BB%D1%8C%D0%B7%D0%BE%D0%B2%D0%B0%D0%BD%D0%B8%D0%B5_%D1%82%D0%B5%D1%80%D0%BC%D0%B8%D0%BD%D0%B0%D0%BB%D0%B0.%D0%A1%D0%BA%D1%80%D0%B8%D0%BD%D1%88%D0%BE%D1%82.png)

## Типы команд

В работе с командной оболочкой используются команды разных типов: встроенные команды, внешние, псевдонимы и функции оболочки.

**Внутренняя, или встроенная команда оболочки** — это команда, которая встроена непосредственно в саму оболочку (например, Bash), а не является отдельным исполняемым файлом. Такие команды обрабатываются непосредственно внутри оболочки, и для их выполнения не требуется создание нового процесса. Пример встроенной команды — `alias`.

**Внешняя команда, или исполняемый файл** — это команда, представляющая собой отдельный исполняемый файл, находящийся в системе. Чтобы выполнить такую команду, нужно указать полный путь до файла. Для выполнения таких команд создается новый процесс.

Команда `ls` не встроена в оболочку, а использует исполняемый файл `ls`, который находится в директории `/usr/bin`.

Взгляните на этот пример. Команда `/usr/bin/ls` делает то же самое, что и `ls`:

Скопировать код

BASH

```
# ls
bin   dev  home  lib32  libx32  mnt  proc  run   srv  tmp  var
boot  etc  lib   lib64  media   opt  root  sbin  sys  usr
# /usr/bin/ls
bin   dev  home  lib32  libx32  mnt  proc  run   srv  tmp  var
boot  etc  lib   lib64  media   opt  root  sbin  sys  usr 
```

Для большинства системных файлов нужно указать только имя файла, и командная оболочка сама найдёт, где он находится. Это возможно благодаря переменной окружения `PATH`. Но обо всём по порядку.

**Псевдоним**, или алиас. Как вы помните, алиас — удобный способ создания короткой формы для часто используемых или сложных команд. Чтобы создать псевдоним используется команда `alias`. Например, `alias lm='ls -m'`. После этого команда `lm` будет эквивалентна `ls -m`.

Посмотреть список использующихся псевдонимов можно выполнив команду `alias` без аргументов.

**Функция оболочки.** Командная оболочка Bash поддерживает и функции, их можно описывать в скриптах или в консоли. Чтобы выполнить функцию, нужно использовать её имя как команду. Вот пример простой функции, которая выполняет две команды сразу: `pwd` и `ls`.

Скопировать код

BASH

```
# my_func () { pwd; ls; }
# my_func
/
bin   dev  home  lib32  libx32  mnt  proc  run   srv  tmp  var
boot  etc  lib   lib64  media   opt  root  sbin  sys  usr 
```

На первой строке происходит создание функции с именем `my_func`. А на второй — вызов этой функции.

Узнать тип команды можно командой `type`. В качестве аргумента нужно передать имя команды. Например, вот типы команд `alias` и созданного псевдонима `lm`.

Скопировать код

BASH

```
# type alias
alias is a shell builtin
# alias lm='ls -m'
# type lm
lm is an alias for ls -m 
```

## Переменные окружения

Переменные окружения, как и переменные в коде, хранят какие-либо значения. Командная оболочка использует эти переменные для своей работы. Она может получать значения переменных или менять их.

Выше мы упомянули переменную `PATH`. Она содержит список каталогов, разделенных двоеточиями `:`, в которых командная оболочка будет искать исполняемые файлы, когда вы вводите команду.

Чтобы вывести значение переменной, нужно выполнить команду `echo $<VAR>`, где вместо `<VAR>` нужно указать имя переменной. Например, вот значение переменной `PATH`.

Скопировать код

BASH

```
# echo $PATH
/usr/local/sbin:/usr/local/bin:/usr/sbin:/usr/bin:/sbin:/bin 
```

Посмотреть список всех переменных можно командой `export`. Она выводит переменные и их значения. Выполните её у себя и посмотрите на результат.

## История и дополнение команд

Выше мы упомянули, что Bash хранит историю команд и умеет дополнять ввод.

## Навигация по файловой системе

Чтобы начать работать с файлами и каталогами, нужно научиться в них ориентироваться.

Работая в терминале, вы всегда находитесь в каком-то каталоге, он называется **рабочий каталог** или **текущая директория**. При запуске терминала вы обычно попадаете в свою пользовательскую директорию, расположенную по пути `/home/$USER`; `$USER` — переменная окружения, где хранится имя пользователя, под которым вы работаете. Например, если имя пользователя — `andrew`, при выводе этой переменной вы увидите:

Скопировать код

BASH

```

```

Проверить, в какой директории сейчас ведётся работа, можно командой `pwd` — она выводит абсолютный путь до текущей директории:

Скопировать код

BASH


**Абсолютный путь** — это путь от корневого каталога системы; он всегда начинается с символа `/`. Есть ещё **относительный путь** — это путь от текущей директории; он начинается c `./`, либо с названия файла или директории, находящихся в текущей категории.

Абсолютный и относительный пути есть у каждого каталога и файла.

Допустим, в пользовательской директории лежит проект `HelloWorld` с файлом `main.go`.

Абсолютный путь для файла `main.go` будет таким: `/home/$USER/HelloWorld/main.go`, а относительный — таким: `./HelloWorld/main.go`.

## Перенаправления

У каждой программы есть стандартный поток для ввода и вывода данных. Например, когда вы пишете `fmt.Print()`, программа пишет это в поток вывода и отображает в терминале. Или когда вы используете `fmt.Scan()`, программа считывает данные, которые пользователь вводит с клавиатуры.

В Linux есть механизм, который называется **перенаправление**. Он позволяет программе считывать данные не из терминала, а из файла, и также выводить данные не в терминал, а файл.

**Как перенаправить поток вывода.** Для этого нужно добавить в конце вызова программы символ `>` и название файла для вывода. Например с помощью такой команды `ls > ls_out.txt` вывод команды `ls` будет записан в файл ls_out.txt. При помощи команды `cat ls_out.txt` можно убедиться, что вывод `ls` действительно сохранился в файле.

Перенаправление позволяет соединять файлы в один. Вы помните, что cat может принять несколько файлов и соединяет их в выводе. С помощью такой команды `cat file1.txt file2.txt file3.txt > result.txt` можно соединить содержимое трёх файлов в одном.

**Как перенаправить поток ввода**. Для этого необходимо в конце запуска программы добавить `< input.txt`, где `input.txt` — это файл с входными данными для программы.

Вот пример программы, которая считывает слово из потока ввода:

Скопировать код

GO

```
package main

import (
    "fmt"
    "log"
)

func main() {
    var str string
    _, err := fmt.Scan(&str) // считываем слово
    if err != nil { // не забываем обрабатывать ошибки
        log.Fatal(err)
    }
    fmt.Println("Я считал из файла: ", str) // выводим строку, которую считали
} 
```

Создайте у себя на компьютере файл `input.txt` и запишите туда какое-нибудь слово; это слово позже вы выведете на экран. Сделать это можно при помощи команды `echo "твоё слово" > input.txt`. Запустите программу и перенаправьте поток ввода командой `go run main.go < input.txt`. В результате программа должна вывести следующее "Я считал из файла: <твоё слово>", где <твоё слово> — это то слово, которое вы записали в файл.

Перенаправление ввода и вывода можно комбинировать. Например, записать вывод прошлой программы в файл можно вот так: `go run main.go < input.txt > output.txt`.

Когда вывод перенаправляется через команду `>`, итоговый файл перезаписывается. Если задублировать символ `>` вот так: `>>`, файл будет не перезаписываться, а дополняться новыми данными. Например, вызов команды `cat file1.txt file2.txt file3.txt > result.txt` аналогичен вызову трёх команд `cat file1.txt > result.txt`, `cat file2.txt >> result.txt` и `cat file3.txt >> result.txt`.

Потренируйтесь: создайте у себя три файла: `file1.txt`, `file2.txt` и `file3.txt`. В первом напишите слово «Десять», во втором — «негритят», а в третьем — «решили пообедать». Выполните три команды из предыдущего абзаца у себя в терминале, чтобы получить результат в файле result.txt. При создании файлов используйте редактор nano.

## Конвейеры

Перенаправлять можно не только вывод данных в файл. Ещё можно перенаправить поток вывода одной программы в поток ввода другой программы. Такая последовательность команд называется **конвейер команд**. Для создания конвейера нужно написать команды и разделить их вертикальной чертой `|`.

Например, с помощью конвейера `ls | sort` можно отсортировать файлы в текущей директории:

11. Сначала выполняется команда `ls`.
12. Результат её выполнения не отображается сразу, а отдается команде `sort`, которая сортирует файлы и каталоги.
13. Команда `sort` выводит отсортированный список на экран.

Вот как это будет работать:

Скопировать код

BASH

```
# touch file1
# touch file3
# touch file2
# ls | sort -r
file3
file2
file1 
```

Конвейер поддерживает перенаправление потока и вывода: результат из прошлого примера можно записать в файл: `ls | sort > sorted.txt`. Попробуйте выполнить команду у себя.

Теперь вы можете посмотреть содержание файла `sorted.txt` с помощью команды `cat`:

Скопировать код

BASH

```
# ls | sort -r > sorted.txt
# cat sorted.txt
sorted.txt
file3
file2
file1 
```

Попробуйте на своём компьютере.

В конвейере может участовать более двух программ, общий синтаксис будет таким: `command1 | command2 | command3 | <следующие команды>`.

# Создание и удаление файлов и каталогов

В этом уроке вы познакомитесь с командами для создания, удаления, перемещения и копирования файлов и каталогов в Linux. А ещё узнаете про концепцию шаблонов подстановки для работы с группами файлов и посмотрите примеры их использования.

## Создание каталогов

Создать каталог можно командой `mkdir` (сокращение от англ. make directory — «создать каталог»). В качестве аргумента команда принимает путь к каталогу, который нужно создать.

В этом уроке все примеры будут показаны в каталоге `tmp` и его подкаталогах. Не забудьте: каталог `tmp` может быть очищен при перезапуске системы.

Следующая команда создаст каталог `lessons` в каталоге `tmp`: `mkdir /tmp/lessons`. Вот как она выглядит в коде:

Скопировать код

BASH

```
# ls /tmp
# mkdir /tmp/lessons
# ls /tmp
lessons 
```

Вот что происходит на каждой из строк:

1. В первой строке командой `ls /tmp` выводится список каталогов в `/tmp`. Видно, что в нём нет каталога `lessons`.
2. Во второй строке создаётся каталог `lessons`.
3. В третьей строке снова выводится список каталогов в `/tmp`. На этот раз в `/tmp` появился каталог `lessons`.

Попробуйте выполнить команду у себя.

Если путь до каталога указан неверно и родительских каталогов нет, команда выведет ошибку. Если нужно создать не только сам каталог, но и родительские каталоги, то нужно указать параметр `-p`. Взгляните на пример:

Скопировать код

BASH

```
# mkdir /tmp/lessons/lesson_1/code
mkdir: cannot create directory '/tmp/lessons/lesson_1/code': No such file or directory
# mkdir -p /tmp/lessons/lesson_1/code
# ls /tmp/lessons
lesson_1
# ls /tmp/lessons/lesson_1
code 
```

Первая команда пытается создать каталог `code` в каталоге `/tmp/lessons/lesson_1`. Но такого каталога нет. И в результате выводится ошибка. Вторая команда использует параметр `-p` и выполняется без ошибок. Можете повторить эти команды у себя и убедиться что в каталоге `/tmp/lessons` появился `lesson_1`.

Если запустить `mkdir` с параметром `-v`, то в консоль будут выведены все директории, которые были созданы в результате выполнения команды.

## Создание файлов

В Linux есть команда `touch`, которая предназначена для создания пустых файлов или обновления их временных меток. В качестве аргумента нужно передать путь файла. Можно указать несколько путей через пробел, тогда команда создаст несколько файлов. При этом все каталоги в пути должны существовать, иначе будет ошибка. Если файл уже существует, то команда обновит время последнего доступа к файлу.

Взгляните на работу команды:

Скопировать код

BASH

```
# touch /tmp/lessons/lesson_1/readme.txt /tmp/lessons/lesson_1/code/main.go 
# ls /tmp/lessons/lesson_1
code readme.txt
# ls /tmp/lessons/lesson_1/code
main.go 
```

Здесь в первой строке создаются два файла:

- файл `readme.txt` по пути `/tmp/lessons/lesson_1/readme.txt`;
- файл `main.go` по пути `/tmp/lessons/lesson_1/code/main.go`.

Следующие команды выводят содержимое каталогов. Видно, что файлы выше действительно создались.

Есть и другие способы создать файл. В предыдущем уроке вы узнали про перенаправление вывода. Это можно использовать для создания файла сразу с содержимым, вот так:

Скопировать код

BASH

```
# echo "Hello" > /tmp/lessons/readme.txt
# ls /tmp/lessons
lesson_1 readme.txt
# cat /tmp/lessons/readme.txt
Hello 
```

Здесь используется команда `echo "Hello" > /tmp/lessons/readme.txt` чтобы создать файл `readme.txt` в каталоге `/tmp/lessons` с содержимым `Hello`. Две другие команды ниже показывают, что файл действительно создан и что в нём записано только одно слово `Hello`.

Чтобы создать пустой файл, предыдущую команду можно изменить так: `echo > /tmp/lessons/readme.txt`.

При таком способе каталоги в пути до файла тоже должны существовать, иначе будет ошибка.

Перенаправление вывода можно использовать и с другими командами, чтобы выводить результат сразу в файл, а не на консоль.

## Удаление файлов и каталогов

Для удаления файлов в Linux используется команда `rm` (англ. remove — «удалить»). В качестве аргумента нужно передать путь до файла.

Команда для удаления файла `readme.txt` в каталоге `/tmp/lessons` будет выглядеть так: `rm /tmp/lessons/readme.txt`. Взгляните на пример:

Скопировать код

BASH

```
# ls /tmp/lessons
lesson_1 readme.txt
# rm /tmp/lessons/readme.txt
# ls /tmp/lessons
lesson_1 
```

В качестве аргументов команде можно передать несколько путей до файлов, тогда она попробует удалить их все. Вот некоторые полезные параметры команды:

- `-i` — запрашивает подтверждение перед удалением каждого файла;
- `-r` — удаляет каталог и всё его содержимое;
- `-f` — принудительно удаляет файл без запроса подтверждения. В некоторых системах команда `rm` может быть псевдонимом для `rm -i`. Параметр `f` избавит вас от подтверждения перед каждым удалением.

Допустим, нужно удалить каталог `/tmp/lessons` со всем содержимым, не подтверждая удаление каждый раз. Сделать это можно такой командой: `rm -rf /tmp/lessons`.

Используйте параметр `-rf` осторожно — ведь файлы удаляются безвозвратно!

Для удаления только пустых каталогов есть ещё одна команда: `rmdir`. В качестве аргументов она принимает один или несколько путей к каталогам. Если каталог не пуст, команда выведет ошибку:

Скопировать код

BASH

```
# mkdir /tmp/lessons
# touch /tmp/lessons/test.txt
# rmdir /tmp/lessons
rmdir: failed to remove '/tmp/lessons': Directory not empty 
```

Можете повторить эти команды у себя и дополнительно изучить справки по командам `rm` и `rmdir`.

## Шаблоны подстановки

Допустим, нужно удалить не один, а все файлы с расширением `.txt`. Это можно сделать разными способами. Самый простой и быстрый — использовать **wildcards** (англ. wildcards — подстановочные знаки). Ещё их называют масками или шаблонами.

**Wildcards** — это символы, которые заменяют набор файлов или каталогов. Они облегчают работу с несколькими файлами, команда получается короче.

Вот основные символы wildcards:

- `*` — соответствует любому количеству символов;
- `?` — соответствует одному любому символу;
- `[]` — соответствует любому из указанных символов внутри скобок;
- `[^]` — соответствует любому символу, кроме указанных внутри скобок после `^`.

Например, чтобы удалить все файлы с `.txt` на конце имени в каталоге `/tmp/lessons`, нужно использовать шаблон `/tmp/lessons/*.txt`. Здесь `*` заменяет любое количество других символов.

Вот как это выглядит на примере:

Скопировать код

BASH

```
# touch /tmp/lessons/test.md /tmp/lessons/test.txt /tmp/lessons/test_2.txt
# touch /tmp/lessons/test_3.txt /tmp/lessons/test_4.md
# ls /tmp/lessons
test.md test.txt test_2.txt test_3.txt test_4.md
# rm /tmp/lessons/*.txt
# ls /tmp/lessons
test.md test_4.md 
```

В начале созданы дополнительные пустые файлы. Затем эти файлы удалены с использованием шаблонов подстановки, а команда `ls /tmp/lessons` выводит оставшиеся. Видно, что команда `rm /tmp/lessons/*.txt` удалила все файлы с `.txt` на конце.

Может показаться, что команда `rm` получает аргумент `/tmp/lessons/*.txt`, а затем переводит его в требуемые совпадения. На самом деле перевод выполняет командная оболочка. После ввода этой команды она видит, что использовались символы подстановки. И перед запуском команды она заменяет шаблон каждым файлом или каталогом, который соответствует этому шаблону.

То есть алгоритм такой:

4. Пользователь вводит команду `rm /tmp/lessons/*.txt`.
5. Система переводит эту команду в такой вид: `rm /tmp/lessons/test.txt /tmp/lessons/test_2.txt /tmp/lessons/test_3.txt`.
6. Система выполняет команду из пункта 2.

Сама команда не видит символы подстановки и не знает, что их применяли. Поэтому шаблоны можно использовать с любыми командами.

Например, вот так можно вывести все файлы, у которых вторая буква `t`:

Скопировать код

BASH

```
# touch /tmp/1test.txt /tmp/2test.txt /tmp/test.md /tmp/test.txt
# ls /tmp/?t*
/tmp/1test.txt /tmp/2test.txt
# ls /tmp
1test.txt 2test.txt lessons test.md test.txt 
```

Здесь в первой строке используется команда `ls` с шаблоном `/tmp/?t*`. Символ `?` заменяется на один любой символ и в данном случае заменит первый символ в названии файла. А `*` заменяется на любые символы и заменит оставшиеся символы в названии. В результате команда выведет все файлы из каталога `/tmp`, где в названии на втором месте стоит буква `t`.

Команда `ls /tmp` показывает список всех файлов в каталоге.

Чтобы посмотреть, на что будет заменён шаблон, можно воспользоваться командой `echo`, которой в качестве аргумента передать шаблон. Например, `echo /tmp/?t*`. В результате на консоль выведется `/tmp/1test.txt /tmp/2test.txt`. Можете попробовать выполнить команду у себя.

Для указания конкретных символов используется `[]`. Шаблон `/tmp/lessons/test_[23].*` будет соответствовать файлам `test_2.txt`, `test_3.txt`, но не `test_4.md`. Взгляните на пример.

Скопировать код

BASH

```
# touch /tmp/lessons/test.md /tmp/lessons/test.txt /tmp/lessons/test_2.txt 
# touch /tmp/lessons/test_3.txt /tmp/lessons/test_4.md
# ls /tmp/lessons
test.md test.txt test_2.txt test_3.txt test_4.md
# echo /tmp/lessons/test_[23].*
/tmp/lessons/test_2.txt /tmp/lessons/test_3.txt 
```

Внутри скобок можно указать диапазон букв или цифр. Например, `[a-z]` будет соответствовать строчным буквам английского алфавита. А `[0-9]` — цифрам от 0 до 9.

Если нужно исключить какие-то символы из поиска, пригодится символ `[^]`. Например, команда `echo /tmp/lessons/test_[^3].*` выведет только `/tmp/lessons/test_2.txt` и `/tmp/lessons/test_4.md`.

## Копирование

Для копирования файлов и каталогов используется команда `cp` (англ. copy — «копировать»). В качестве аргумента команда принимает один или несколько источников и только одно место назначения. Источником и местом назначения могут быть файлы или каталоги. Ниже приведены различные сценарии команды `cp`.

**Копирование файла в файл.** Пример команды: `cp /tmp/test.txt /tmp/lessons/test_copy.txt`. Здесь `/tmp/test.txt` — файл, который нужно скопировать, `/tmp/lessons/test_copy.txt` — место, куда будет скопирован файл. Таким образом в каталоге `/tmp/lessons` появится копия файла `test.txt` только с новым именем `test_copy.txt`. Изучите команду в примере ниже. Если у вас нет каталога `lessons` в каталоге `tmp`, создайте его.

Скопировать код

BASH

```
# touch /tmp/test.txt
# ls /tmp
lessons test.txt
# cp /tmp/test.txt /tmp/lessons/test_copy.txt
# ls /tmp/lessons
test_copy.txt 
```

Если файл уже существует, он будет перезаписан. Чтобы команда каждый раз спрашивала подтверждение перед перезаписью, нужно передать параметр `-i`. Если указать `-n`, то файлы не будут перезаписываться. Это можно использовать для копирования только отсутствующих файлов. Попробуйте повторить у себя команду из примера, но указав параметр `-i`.

Если указать параметр `-a`, то у копии сохранятся атрибуты оригинального файла, например, права доступа, временные метки и другие.

**Копирование файла в каталог.** В предыдущем примере имя нового файла было прописано явно. Но можно в качестве назначения указать каталог, тогда файл будет скопирован со своим именем. Вот пример:

Скопировать код

BASH

```
# cp /tmp/test.txt /tmp/lessons
# ls /tmp/lessons
test.txt test_copy.txt 
```

**Копирование каталога в каталог.** Для рекурсивного копирования каталога со всем содержимым нужно передать параметр `-r`, вот так:

Скопировать код

BASH

```
# mkdir /tmp/lesson_1
# touch /tmp/lesson_1/test.txt
# ls /tmp
lesson_1 lessons test.txt
# cp -r /tmp/lesson_1 /tmp/lessons
# ls /tmp/lessons
lesson_1 test.txt test_copy.txt 
```

Здесь каталог `lesson_1` из `/tmp` копируется в каталог `/tmp/lessons`.

**Копирование содержимого каталога**. В этом случае копируется не сам каталог, а только его содержимое. Для этого к параметру `-r` нужно дополнительно указать параметр `-T`. При этом каталог назначения должен существовать, иначе будет ошибка. Взгляните на пример:

Скопировать код

BASH

```
# mkdir /tmp/lesson_2
# cp -r -T /tmp/lesson_1 /tmp/lessons/lesson_2
# ls /tmp/lessons/lesson_2
test.txt 
```

Здесь создан пустой каталог `lesson_2`. Затем в него скопировано содержимое каталога `lesson_1`. Команда `ls /tmp/lessons/lesson_2` показывает, что в каталог `lesson_2` скопировано только содержимое каталога `lesson_1`, но не сам `lesson_1`.

С командами копирования тоже можно использовать шаблоны подстановки. Копирование содержимого каталога в другой каталог из предыдущего можно выполнить вот такой командой: `cp -r /tmp/lesson_1/* /tmp/lessons/lesson_2`. Однако в таком случае не будут скопированы скрытые файлы и каталоги.

Вот ещё один пример с шаблонами: `cp /tmp/*.txt /tmp/lessons`. Эта команда позволяет скопировать все файлы с расширением `*.txt` из каталога `/tmp/` в `/tmp/lessons`.

## Перемещение

Для перемещения файлов и каталогов используется команда `mv` (англ. move — «перемещать»). Работа с ней похожа на работу с командой `cp`. В качестве аргумента команда принимает один или несколько источников и только одно место назначения. Источником и местом назначения могут быть файлы или каталоги.

**Перемещение файла.** Вот так будет выглядеть команда для перемещения файла: `mv /tmp/test.txt /tmp/lessons`. Запустите у себя код из примера ниже. Перед этим можете удалить всё из каталога `tmp`, чтобы не мешались лишние файлы и каталоги.

Скопировать код

BASH

```
# mkdir /tmp/lessons
# touch /tmp/test.txt
# ls /tmp
lessons test.txt
# mv /tmp/test.txt /tmp/lessons
# ls /tmp
lessons
# ls /tmp/lessons
test.txt 
```

В каталоге `/tmp` создан пустой каталог `lessons` и файл `test.txt`. После выполнения команды перемещения в каталоге `/tmp` остался только каталог `lessons`, где теперь есть файл `test.txt`. То есть файл `test.txt` переместился из каталога `/tmp` в `/tmp/lessons`.

Если файл с таким именем уже существует в месте назначения, его можно перезаписать. Для этого надо указать параметр `-f`. Команда также поддерживает параметр `-n`, благодаря которому файлы не будут перезаписаны при перемещении.

**Переименование файла.** Команду `mv` можно использовать и для переименования файла. Нужно указать тот же каталог назначения, что и у исходного файла, но другое имя файла. Команда будет выглядеть так: `mv /tmp/test.txt /tmp/test.md`. После этого файл в каталоге `/tmp` сменит имя с `test.txt` на `test.md`.

Файл можно переименовать вместе с перемещением в другой каталог. Нужно лишь указать другое имя файла. Например, это можно сделать такой командой: `mv /tmp/test.txt /tmp/lessons/test_1.txt`. Тогда в каталоге `/tmp/lessons` будет файл `test_1.txt`.

**Перемещение каталога.** Вот пример команды для перемещения каталога: `mv /tmp/lessons /tmp/temp`. Эта команда переместит каталог `/tmp/lessons` в `/tmp/temp`:

Скопировать код

BASH

```
# mkdir /tmp/temp
# ls /tmp
lessons temp
# mv /tmp/lessons /tmp/temp
# ls /tmp/temp
lessons 
```

После выполнения команды в пустом каталоге `/tmp/temp` появился каталог `lessons`.

# Поиск файлов и каталогов

Иногда на компьютере приходится искать какие-то файлы. Или текст внутри файлов — например, нужные строки в логах. Открывать вручную разные каталоги и файлы долго, утомительно и неэффективно. В Linux есть инструменты для быстрого поиска нужных файлов и каталогов по различным критериям: имени, типу, размеру, дате изменения и прочим. А также для поиска по содержимому файлов. В этом уроке вы познакомитесь с этими инструментами и научитесь использовать пайпы и перенаправления для более сложных запросов поиска и дальнейшей обработки найденных данных.

## Поиск файлов и каталогов

Для поиска файлов и каталогов можно использовать команду `find`. В ней можно указать имя файла, тип, размер, дату изменения и другие критерии. Команда имеет следующий синтаксис: `find <каталог> <параметры> <шаблон>`, где:

- `<каталог>` — путь до каталога, в котором нужно искать файлы.
- `<параметры>` — параметры команды для задания критериев поиска.
- `<шаблон>` — имя файла или шаблон для поиска файлов. В качестве шаблона можно использовать шаблон подстановки, про который вы узнали в предыдущих уроках.

Вот основные параметры команды для задания критериев поиска:

- `-type f` — искать только файлы.
- `-type d` — искать только каталоги.
- `-name` — поиск по имени.
- `-iname` — регистронезависимый поиск по имени файла. Например, если указать `test.txt`, найдёт также и `TEST.txt`. i — сокращение от англ. insensitive, нечувствительный.
- `-mtime` — поиск по времени модификации файла. В качестве аргумента указывается количество суток. m — сокращение от англ. modification, изменения.
- `-mmin` — поиск по времени модификации файла. В качестве аргумента указывается количество минут.
- `-atime` — поиск файлов по дате последнего чтения. В качестве аргумента указывается количество суток. a — сокращение от англ. access, доступ.
- `-newer` — найти файлы новее, чем указанный.
- `-size` — поиск файлов по их размеру.
- `-maxdepth` и `-mindepth` — ограничивает глубину поиска вложенных каталогов. Например, если нужно искать только в указанном каталоге и не смотреть во вложенных. От англ. depth, глубина.
- `-empty` — искать пустые файлы и каталоги.

#### **Поиск по имени**

Вот простой пример использования команды: `find /tmp`. Покажет всё что лежит в `/tmp`, включая содержимое вложенных каталогов.

С командой `find` можно использовать шаблоны для поиска по части имени. Вот пример команды для поиска файла начинающегося на `test.` в каталоге `/tmp`:`find /tmp -name "test.*"`. Если не имеет значения, какой регистр используется в имени файла, вместо параметра `-name` можно использовать `-iname`. Взгляните на пример:

Скопировать код

BASH

```
# mkdir /tmp/temp
# touch /tmp/test.txt
# touch /tmp/temp/test.txt
# touch /tmp/temp/Test.txt
# find /tmp -name "test.*"
/tmp/temp/test.txt
/tmp/test.txt
# find /tmp -iname "test.*"
/tmp/temp/test.txt
/tmp/Test.txt
/tmp/test.txt 
```

Сначала создаётся каталог `temp` и дополнительные файлы в каталоге `tmp`. Команда `find /tmp -name "test.*"` нашла только файлы, начинающиеся на `test.`, без заглавных букв. Следующая команда дополнительно нашла файл `Test.txt`. Обе команды выполнили поиск во внутреннем каталоге `temp`.

Критерии поиска можно комбинировать. Чтобы искать только в `/tmp` и не искать во вложенных каталогах, можно указать параметр `-maxdepth 1`, который задаёт глубину поиска равную 1. Пример команды: `find /tmp -maxdepth 1 -name "test.*"`.

Для поиска только каталогов нужно указать параметр `-type d`. Например, вот команда, которая поможет найти все каталоги в `/var`, которые начинаются на `l`: `find /var -maxdepth 1 -type d -name "l*"`

#### **Поиск по дате**

Допустим, нужно найти файлы в каталоге `/var`, которые изменились сутки назад. Вот как это можно сделать: `find /var -mtime 1`. Если нужно указать примерное количество дней, перед числом нужно поставить знак `+` или `-`: искать больше или меньше указанного значения. Например, команда `find /var -mtime -1` найдёт все файлы, которые изменились меньше суток назад.

Если нужно вместо суток фильтровать по минутам, есть параметр `-mmin`. Его использование аналогично параметру `-mtime`. Например, вот так можно найти файлы в каталоге `/tmp`, изменённые за последние 5 минут: `find /tmp -mmin -5`.

Чтобы искать в диапазоне времени, нужно использовать параметры `-mtime` и `mmin` два раза. Например, вот команда для поиска файлов в каталоге `/tmp`, с момента изменения которых прошло от 1 до 5 минут: `find /tmp -mmin +1 -mmin -5`.

Параметр `-newer` в качестве аргумента принимает другой файл. С его помощью можно найти файлы, у которых дата модификации больше, чем у указанного файла. Например, если вам нужно найти файлы новее определённой даты, вы можете сделать следующее:

1. Создать новый файл и изменить ему дату модификации на требуемую с помощью команды `touch`.
2. Указать созданный файл в качестве аргумента параметру `-newer`.

Команда для поиска в каталоге `/tmp` будет выглядеть так: `find /tmp -newer /tmp/temp.txt`, где `/tmp/temp.txt` — созданный файл с нужной датой модификации.

Также для поиска можно использовать и какой-то из старых файлов, если это нужно для ваших задач.

#### **Поиск по размеру**

Для поиска по размеру файла используется параметр `-size`. Значения для него нужно указать в формате: `<знак>N<множитель>`. Здесь `<знак>` — это одно из двух значений:

- `+` — поиск файлов, размер которых БОЛЬШЕ указанного.
- `-` — поиск файлов, размер которых МЕНЬШЕ указанного.

Если знак не указан, будут искаться файлы с заданным размером.

`N` — число, размер файла. `<множитель>` — это одно из значений:

- `c` — 1 байт
- `w` — 2 байта
- `b` — 512 байт (используется по умолчанию).
- `k` — 1 КБ (килобайт)
- `M` — 1 МБ (мегабайт)
- `G` — 1 ГБ (гигабайт)

Например, чтобы найти файлы меньше двух мегабайт, нужно указать `-size -2M`. Полностью команда будет выглядеть, например, так: `find /var -size -2M`.

Для поиска в промежутке между размерами можно указать два параметра `-size`. Например, эта команда `find /var -size +10k -size -100k` найдёт все файлы, размер которых больше 10, но меньше 100 КБ.

#### **Действия с результатами**

Команда `find` может выполнить над результатами поиска указанные действия. Вот список параметров:

- `-delete` — удаляет найденные файлы.
- `-ls` — выводит более подробную информацию о файлах.
- `-print` — показывает полный путь к найденным файлам. Используется по умолчанию, если не указать другое действие.
- `-exec` — выполняет указанную команду для каждого найденного файла.

Например, вот так можно удалить все пустые файлы и каталоги в каталоге `/tmp`: `find /tmp -empty -delete`.

Чтобы скопировать найденные файлы, нужно использовать параметр `-exec`, которому в качестве аргумента передать команду копирования.

Например, чтобы скопировать файлы в каталог `/tmp/lessons`, нужно передать такой аргумент: `cp {} /tmp/lessons \;`. Здесь вместо `{}` будут поставлены все найденные файлы. А символы `\;` означают конец команды. Полностью команда поиска и копирования будет выглядеть так: `find /tmp -name "t*" -exec cp {} /tmp/lessons \;`.

## Поиск в файлах

Для поиска текста в файлах можно использовать команду `grep` (англ. search Globally for lines matching the Regular Expression, and Print them — глобальный поиск строк, соответствующих регулярному выражению, и их печать). Это одна из самых популярных команд, которая есть почти во всех дистрибутивах Linux.

Синтаксис команды следующий: `grep <параметры> <шаблон> <файл>`, где:

- `<параметры>` — дополнительные параметры, с помощью которых указываются различные настройки поиска и вывода. Например, не учитывать регистр или вывести количество строк.
- `<шаблон>` — любая строка или регулярное выражение, по которому будет выполняться поиск.
- `<файл>` — место, где будет выполняться поиск. `grep` позволяет искать в нескольких файлах и даже в каталоге, используя рекурсивный режим.

Вот некоторые полезные параметры команды:

- `-i` — регистр символов учитываться не будет. То есть `текст`, `ТЕКСТ`, `Текст` и другие вариации слова будут считаться эквивалентными.
- `-n` — выводит номер строки, в которой найден шаблон.
- `-H` — выводит имена файлов, в которых найден шаблон.
- `-e` — позволяет указать несколько шаблонов поиска.
- `-F` — рассматривать шаблон поиска как обычную строку, а не регулярное выражение. Если в шаблоне есть спецсимволы регулярных выражений (например, `[`), то без этого параметра команда выведет ошибку.
- `-E` или `--extended-regexp` — включить расширенный режим регулярных выражений.
- `A<n>` или `--after-content` — выводит найденную строку и `<n>` строк ПОСЛЕ неё.
- `B<n>` или `--before-content` — выводит найденную строку и `<n>` строк ДО неё.
- `C<n>` — выводит найденную строку и `<n>` строк ДО и ПОСЛЕ неё.
- `-r` — поиск во всех файлах каталога и подкаталогов.
- `--exclude` — пропустить файлы, имена которых соответствуют регулярному выражению.

#### Регулярные выражения

Имеется два вида регулярных выражений: базовые (BRE — basic regular expressions, базовые регулярные выражения) и расширенные (ERE — extended regular expressions, расширенные регулярные выражения).

BRE поддерживают набор символов, позволяющих описать каждый определённый символ в строке. Это: `.`, `*`, `[]`, `[^]`, `^` и `$`. BRE используются в `grep` по умолчанию. Если нужно рассматривать шаблон поиска не как регулярные выражения, а как простой текст, нужно указать параметр `-F`.

В дополнение ко всем символам из базового синтаксиса, в ERE поддерживаются также такие символы:

- `+` — одно или больше повторений предыдущего символа.
- `?` — ноль или одно повторение предыдущего символа.
- `{n,m}` — повторение предыдущего символа от n до m раз.
- `|` — позволяет объединять несколько шаблонов.

Для использования ERE нужно указать параметр `-E`. Выше вы видели, как найти строки с предупреждениями и ошибками: `grep -e "warn" -e "error" /tmp/test.log`. С помощью ERE его можно переписать так: `grep -E "warn|error" /tmp/test.log`.

Вот ещё один пример поиска с использованием регулярных выражений. Допустим, нужно найти все записи в определённом промежутке времени. С этим поможет шаблон: `2023-12-25T13:4[5-9]`. В данном случае `[5-9]` означает любое число в диапазоне с 5 до 9. Это значит, что найдутся все строки, где есть `2023-12-25T13:45`, `2023-12-25T13:46`, `2023-12-25T13:47`, `2023-12-25T13:48` или `2023-12-25T13:49`. Сама команда будет выглядеть так: `grep "2023-12-25T13:4[5-9]" /tmp/test.log`.

#### **Фильтрация вывода**

Вы уже знакомы с пайпами — с их помощью можно отфильтровать вывод команд. Например, команда `dpkg -l` выводит список всех установленных пакетов. Список может быть большим, и найти среди него что-то конкретное сложно. Команда `grep` сильно упростит поиск. Например, вам нужно узнать, есть ли среди установленных пакетов tar. Для этого можно воспользоваться командой: `dpkg -l | grep tar`. Взгляните на результат:

Для поиска в каталогах нужно указать параметр `-r`. Вот так будет выглядеть команда поиска слова `error` в каталоге `/tmp`: `grep -r "error" /tmp`. Посмотрите на результат.

Скопировать код

BASH

В выводе не только найденная строка, но и путь до файла, в котором эта строка нашлась.

Если нужно исключить какие-то файлы из поиска, пригодится параметр `--exclude`. В качестве аргумента этой команде через знак `=` нужно указать шаблон, по которому будут исключены файлы. Вот так, например, можно исключить все файлы с расширением `log`: `grep -r --exclude="*.log" "error" /tmp`.

#### **Сохранение результата**

## Комбинирование команд

Команда `find` позволяет находить файлы по заданным критериям и выполнять другие команды над найденными файлами с помощью параметра `-exec`. А команда `grep` хорошо справляется с задачей поиска внутри файлов. Эти две команды можно использовать вместе для точного поиска нужной информации. Вот как это можно использовать.

Допустим, нужно найти все ошибки в логах за последний день. Файлы с логами имеют расширение `.log` и лежат в каталоге `/tmp`. Команда для поиска будет выглядеть так: `find /tmp -mtime -1 -name "*.log" -exec grep -H "error" {} \;`, где:

- `find /tmp -mtime -1 -name "*.log"` — находит все файлы с расширением `.log` в каталоге `/tmp`, которые изменились за последний день.
- `grep -H "error" {}` — ищет все строки, содержащие `error` и выводит на консоль вместе с именем файла, в котором найдена строка. Вместо `{}` будут поставлены все найденные файлы.
