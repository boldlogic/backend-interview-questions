мьютексы



Тип `sync.Mutex` — примитив, реализующий мьютекс в Go. Для переменной этого типа можно вызвать два метода:

- `(m *Mutex) Lock()` — блокирует мьютекс. Заблокировать мьютекс может только одна горутина. Если другая горутина вызывает этот метод, а мьютекс уже заблокирован, то она будет ждать его освобождения.
- `(m *Mutex) Unlock()` — разблокирует мьютекс. Горутина должна освободить мьютекс сразу после того, как она закончила выполнение критической секции.



- Мьютекс — примитив синхронизации, который следует блокировать перед работой с общими данными и разблокировать после. Если мьютекс заблокирован, другие горутины будут ждать его освобождения.
- Мьютекс блокируется методом `Lock()`, а разблокируется методом `Unlock()`. Важно не забывать освобождать мьютекс.
- Нельзя для одних горутин ограничивать доступ к данным с помощью мьютекса, а для других — оставлять доступ свободным.

Будьте внимательны при вызове методов разблокировки. Если был вызван `Lock()`, то затем следует вызывать `Unlock()`. При использовании `RLock()`, мьютекс разблокируется вызовом `RUnlock()`, но никак не обычным `Unlock()`.


```go
package main

import (
    "fmt"
    "sync"
    "time"
)

type Map struct {
    mu sync.RWMutex
    m  map[string]string
}

func (m *Map) Get(key string) string {
    // RLock() даёт возможность нескольким горутинам читать данные
    m.mu.RLock()
    defer m.mu.RUnlock()
    return m.m[key]
}

func (m *Map) Set(key string, v string) {
    // Lock() блокирует все операции
    m.mu.Lock()
    defer m.mu.Unlock()
    m.m[key] = v
}

func main() {
    m := Map{
        m: make(map[string]string),
    }
    for i := 0; i < 10; i++ {
        go func() {
            for {
                m.Set("a", ".")
                time.Sleep(50 * time.Millisecond)
            }
        }()
    }

    for i := 0; i < 10; i++ {
        go func() {
            count := 0
            for {
                v := m.Get("a")
                count++
                if count%10 == 0 {
                    fmt.Print(v)
                }
                time.Sleep(20 * time.Millisecond)
            }
        }()
    }
    time.Sleep(1 * time.Second)
}
```


## Взаимные блокировки

- С одной стороны мьютексы позволяют избежать состояния гонки, а с другой могут быть причиной взаимных блокировок.


**Потокобезопасность** заключается в корректной работе алгоритмов, функций, структур данных при наличии множества горутин, выполняющих эти операции. Например, функции пакета `fmt` потокобезопасны, вы можете спокойно использовать `fmt.Println()` в разных горутинах.


Потокобезопасность типа означает, что все операции с экземплярами данного типа будут потокобезопасными, то есть будет обеспечен правильный результат при работе множества горутин, выполняющих эти операции. Из предыдущих уроков вы уже поняли, что `int` и `map` нельзя считать потокобезопасными
