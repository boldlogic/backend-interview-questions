# Уровень контейнеров. Задача и целевая аудитория

Контекст контейнеров нужен, чтобы:

*   Явно описывать технологии реализации
*   Описывать связи между отдельными частями системы и способы их взаимодействия

Целевая аудитория: инженеры, техническая поддержка и операционная команда.

Диаграмма уровня контейнеров является обязательной для каждой системы.
