# Уровень контейнеров. Назначение

Уровень контейнеров показывает состояние внутри рамок одной системы, отображая контейнеры внутри него.

Контейнеры на диаграмме дают информацию о том, как выполняются функции системы в ее архитектуре, основные технологические детали, взаимодействия между контейнерами. Этот уровень сфокусирован на технологиях и отвечает на вопросы:

*   Какие основные части информационной системы?
*   Какие основные технологические решения приняты?
*   Как функции реализуются внутри системы?
*   Каким образом и для чего части системы взаимодействуют?
*   В какой части системы я должен написать код для реализации функции, если я разработчик?
