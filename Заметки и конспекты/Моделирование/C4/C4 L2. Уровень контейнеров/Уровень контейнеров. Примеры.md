# Уровень контейнеров. Примеры

Контейнер — это что-то, что «владеет» кодом или данными, как приложения или хранилища данных. Контейнеры нужны, чтобы система была работоспособна.

## Примеры типов контейнеров

*   **Клиентское десктоп приложение:** Например, Microsoft Word, установленный на машину пользователя.
*   **Микросервис:** Например, Java-сервис, реализующий функцию расчета бонуса за покупку.
*   **Мобильное приложение:** Например, приложение магазина Лемана Про для Android.
*   **База данных:** Например, схема PostgreSQL, которая хранит данные о сотрудниках компании.
*   **Скрипт:** Например, скрипт, запускающийся в системе каждую ночь для расчета ежедневной выручки.
*   **Веб-приложение:** Например, сайт, где можно найти исполнителя для мелких бытовых работ.

## Примеры контейнеров на диаграммах

Ниже представлены примеры контейнеров, как они могут быть отображены на диаграммах C4:

*   **sap-adapter**
    *   **Тип контейнера:** Java SpringBoot
    *   **Описание:** Адаптер для SAP ERP, переводит формат сообщения в JSON.

*   **IOS приложение курьера**
    *   **Тип контейнера:** Flutter for IOS
    *   **Описание:** Приложение для курьеров Лемана Про. Дает перечень доставок и возможность отмечать выполнение.

*   **delivery-reserve-service**
    *   **Тип контейнера:** PG SQL DB
    *   **Описание:** Хранит данные со слотами доставки и занятыми слотами доставки.
