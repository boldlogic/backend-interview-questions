# Уровень контейнеров. Как рисовать

На этом уровне детализируется архитектура системы, показывая ее основные технические компоненты (контейнеры) и их взаимодействие с пользователями и внешними системами. Ниже приведены правила для создания таких диаграмм.

## Правила построения диаграммы уровня контейнеров

1.  Нарисовать границу системы, в которую входят контейнеры пунктирным прямоугольником.
2.  Отобразить все контейнеры в виде прямоугольников. Каждый контейнер – отдельно разворачиваемая (deploy-able) сущность.
3.  Отобразить хранилища данных.
4.  Внешних контрагентов отобразить, как системы.
5.  Пользователей отобразить в виде иконки человека.
6.  Описывать взаимодействия между всеми элементами диаграммы.
7.  Указать метаданные для каждого объекта: контейнеров, баз данных, границы, внешних систем, связей.
8.  Пунктирными прямоугольниками отобразить логические и технологические границы.

## Пример диаграммы уровня контейнеров: Клиентская банковская система

### Легенда
*   **Пользователь:** (Темно-синяя иконка человека)
*   **Контейнер:** (Светло-синий прямоугольник или цилиндр)
*   **Внешний пользователь:** (Темно-серый человек)
*   **Внешняя программная система:** (Темно-серый прямоугольник)

### Описание взаимодействия

Диаграмма демонстрирует клиентскую банковскую систему, включающую в себя:

*   **Клиент банка** (Пользователь): взаимодействует с Single-page приложением и Мобильным приложением, просматривает баланс счета и проводит платежи.
*   **Single-page приложение** (Контейнер: JavaScript и Angular): обеспечивает функциональность пользователю через UI веб-браузера. Делает запросы (JSON/HTTPS) к API gateway.
*   **Мобильное приложение** (Контейнер: Flutter): обеспечивает ограниченную функциональность в рамках мобильного приложения. Делает запросы (JSON/HTTPS) к API gateway.
*   **API gateway** (Контейнер: Java и Spring MVC): обеспечивает функциональность управления API запросов. Делает запросы (JSON/HTTPS) к Базе данных и АБС системе банка.
*   **База данных** (Контейнер: Postgre): хранит информацию о пользователях, логирует историю и т.д. Читает и записывает данные (SQL, JDBC) из API gateway.
*   **Система рассылки оповещений** (Внешняя программная система): получает сообщения от АБС системы банка.
*   **АБС система банка** (Внешняя программная система): хранит всю информацию о клиенте, счетах, транзакциях и т.д. Делает запросы (JSON/HTTPS) к API gateway и рассылает сообщения в Систему рассылки оповещений.
*   **Специалист технической поддержки** (Пользователь): помогает пользователю в случае сбоев или сложностей. Выполняет исправления в системе, взаимодействуя с АБС системой банка.
