# Цели создателя нотации С4

Саймон Браун хотел создать одну нотацию, которая позволит:

* Описывать статичные модели архитектуры ПО
* Иметь иерархичный набор «карт», которые позволяют менять масштаб рассмотрения
* Решить проблему описания разных уровней архитектуры через введение уровней с четким определением их применения
* Иметь единую терминологию для моделирования
* Сделать гибкую нотацию со слабыми ограничениями в ее использовании, которая позволит пользователям вводить свои нормы и ограничения для команды/компании.
