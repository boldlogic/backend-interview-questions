# Уровень компонентов (Component Level)

Каждый контейнер – это «сборная» сущность, который может быть запрограммирован из нескольких компонентов. Все эти компоненты вместе выполняют функции, возложенные на контейнер.

Слово «компонент» обычно используется для описания массы смыслов. Автор определяет «компонент», как «группу связанной функциональности, которая инкапсулирована (сокрыта внутри компонента) за четко определенным интерфейсом». 

## Примеры компонентов:

*   Общая библиотека функций, которая используется программистами или системами.
*   JAR файл, который содержит в себе программу или ее часть, написанную на языке Java.

Диаграмма компонентов показывает состояние внутри рамок одного контейнера, то есть компоненты внутри него.

## Пример диаграммы уровня компонентов: API Gateway банковской системы

### Легенда
*   **Контейнер:** (Синий прямоугольник с верхней панелью)
*   **Компонент:** (Светло-синий прямоугольник)
*   **Внешняя программная система:** (Темно-серый прямоугольник)

### Описание элементов и взаимодействий

Диаграмма иллюстрирует внутреннюю структуру контейнера **API Gateway** банковской системы, показывая компоненты и их взаимодействие с внешними системами.

**Контейнеры верхнего уровня:**
*   **Single-page приложение** (Контейнер: JavaScript и Angular) — обеспечивает функциональность пользователю через UI веб-браузера. Делает запросы (JSON/HTTPS) к API Gateway.
*   **Мобильное приложение** (Контейнер: Flutter) — обеспечивает функциональность пользователю через UI мобильного приложения. Делает запросы (JSON/HTTPS) к API Gateway.

**Компоненты внутри API Gateway:**
*   **Компонент входа** (Компонент: Spring MVC Rest Controller) — позволяет пользователям авторизоваться.
*   **Компонент сброса пароля** (Компонент: Spring MVC Rest Controller) — позволяет пользователям сбросить пароль.
*   **Компонент счетов клиента** (Компонент: Spring MVC Rest Controller) — обеспечивает клиентам просмотр информации по счетам.
*   **Компонент безопасности** (Компонент: Spring Bean) — функциональность, связанная с входом, сменой пароля и т.д.
*   **Компонент рассылки уведомлений** (Компонент: Spring Bean) — отправляет уведомления пользователям.
*   **"Фасад" к АБС системе банка** (Компонент: Spring Bean) — фасад над системой АБС.

**Взаимодействия:**
*   **Компонент входа** и **Компонент сброса пароля** используют **Компонент безопасности**.
*   **Компонент сброса пароля** использует **Компонент рассылки уведомлений**.
*   **Компонент счетов клиента** использует **"Фасад" к АБС системе банка**.
*   **Компонент рассылки уведомлений** делает запросы (JSON/HTTPS) к **Системе рассылки оповещений** (внешняя программная система).
*   **"Фасад" к АБС системе банка** делает запросы (JSON/HTTPS) к **АБС системе банка** (внешняя программная система, хранит всю информацию о клиентах, счетах, транзакциях и т.д.).
*   **API Gateway** читает и записывает данные (SQL) в **Базу данных** (Контейнер: PostgreSQL), которая хранит информацию о пользователях, логирует историю и т.д.
