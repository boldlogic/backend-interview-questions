# Уровень компонентов. Назначение

Уровень компонентов показывает состояние внутри рамок одного контейнера, отображая компоненты внутри него.

Контекст компонентов нужен, чтобы:

*   Явно описать, из каких пакетов кода состоит каждый контейнер и за что они отвечают
*   Показывают взаимосвязь компонентов
*   Показывает детали решений, включая фреймворки, общие компоненты и библиотеки
*   Если диаграмма точно отражает пакеты кода, она является картой для применения изменений и показывает структуру кодовой базы
