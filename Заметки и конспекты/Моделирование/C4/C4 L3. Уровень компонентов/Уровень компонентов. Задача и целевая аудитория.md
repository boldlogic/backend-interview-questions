# Уровень компонентов. Задача и целевая аудитория

## Диаграмма компонентов отвечает на вопросы:

*   Из каких компонентов состоит контейнер?
*   К каким контейнерам относятся компоненты?
*   Как работает определенное программное обеспечение «под капотом»?

## Целевая аудитория

Целевая аудитория — разработчики системы, техническая поддержка, системные аналитики.

## Применимость

Диаграмма уровня компонентов не является обязательной для каждой системы. Её реализация зависит от необходимости для команды разработки. Такая диаграмма скорее всего будет неинформативна для хранилищ данных или контейнеров с простой реализацией.

Диаграмма компонентов хорошо применима для монолитных систем, где вся функциональность реализована в одном контейнере.
