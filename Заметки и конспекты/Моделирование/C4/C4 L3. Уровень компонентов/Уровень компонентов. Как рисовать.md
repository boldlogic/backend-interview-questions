# Уровень компонентов. Как рисовать

На этом уровне детализируется внутренняя структура контейнера, показывая его компоненты и их взаимодействие с внешними системами и хранилищами данных. Ниже приведены правила для создания таких диаграмм.

## Правила построения диаграммы уровня компонентов

1.  Нарисовать пунктирным прямоугольником границу контейнера, в который входят компоненты.
2.  Отобразить все компоненты в виде прямоугольников.
3.  Отобразить в виде контейнеров хранилища данных (как базы данных) или интеграционные системы (как Kafka), с которыми взаимодействуют компоненты.
4.  Системы, с которыми взаимодействует компонент, отобразить, как внешние системы.
5.  Пользователей отобразить в виде иконки человека.
6.  Стрелками описываем взаимодействия между элементами диаграммы.
7.  Указать метаданные для каждого объекта.
8.  Пунктирными прямоугольниками отобразить логические и технологические границы.
