# Уровень системы. Задача и целевая аудитория

Системный контекст нужен, чтобы:

* Делать явными среду и область применения системы
* Показывать, что добавляется (разрабатывается) или убирается в ландшафте
* Давать начальное понимание для диалога между инженерами и бизнесом, не нагружая излишними деталями
* Направлять к нужной системе, в случае проблем с одним из взаимодействий

Целевая аудитория: команды разработки ПО и представители бизнеса.

Диаграмма уровня системы является обязательной для каждой системы.
