# Уровень системы. Элементы и метаданные

На системном контексте обычно отображаются пользователи, системы, границы и взаимодействия:

| Элемент        | Метаданные                                                                                                                                   | Пример                                                                                                                                                         |
| -------------- | -------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Пользователи   | Название роли (конкретный человек или группа, пользователь, актор, персона)<br>Описание - короткое указание роль и основной задачи в системе | [Person]<br>Person name<br>Description of person<br><br>[Person]<br>External person name<br>Description of external person                                     |
| Системы        | Название системы<br>Описание — короткое описание и основной функционал                                                                       | [Software System]<br>System name<br>Description of software system<br><br>[Software System]<br>External system name<br>Description of external software system |
| Взаимодействия | Каждое взаимодействие между людьми и системами<br>Описание взаимодействия                                                                    | e.g. Visits pages                                                                                                                                              |
| Границы        | Корпоративные или логические границы, которые описывают принадлежность элементов к группам, классам и т.д.                                   | [boundary]<br>boundary name                                                                                                                                    |
