# Go: рефлексия

## Шпаргалка

1. Информация о типе из значения во время выполнения.
2. `reflect.TypeOf` / `reflect.ValueOf`.
3. Не в горячем пути — медленно.

---

## Зачем

**Рефлексия** — узнать тип и структуру значения **во время выполнения**, когда конкретный тип неизвестен при компиляции.

Типичные места: [`encoding/json`](https://pkg.go.dev/encoding/json) (marshal/unmarshal по struct tags), RPC, ORM, отладка и дамп структур.

В большинстве прикладного кода reflect не нужен; для сериализации часто выбирают **генерацию кода** или **generics** (Go 1.18+).

---

## TypeOf, ValueOf, Kind

```go
v := reflect.ValueOf(x)
t := v.Type()           // или reflect.TypeOf(x)
k := v.Kind()           // struct, ptr, slice, … — не путать с именованным типом
```

`Kind` — базовая категория (struct, int); `Type` — именованный тип пользователя.

`Value.Elem()` — разыменование для pointer/interface Value.

`NumField()`, `Field(i)` — поля struct (после проверки `Kind == Struct`). Имя поля — из `Type.Field(i).Name`, теги — из `StructField.Tag`.

Короткий обход полей:

```go
v := reflect.ValueOf(obj)
if v.Kind() == reflect.Ptr {
    v = v.Elem()
}
if v.Kind() != reflect.Struct {
    return
}
for i := 0; i < v.NumField(); i++ {
    f := v.Field(i)
    name := v.Type().Field(i).Name
    _ = name
    _ = f
}
```

`IsZero()`, `IsNil()` — сравнение с zero/nil (для типов, допускающих nil).

`reflect.DeepEqual(a, b)` — рекурсивное сравнение; дорого, в горячем пути лучше явный `Equal()`.

## Struct tags

Теги в backticks у поля struct:

```go
type User struct {
    ID   int    `json:"id"`
    Name string `json:"name,omitempty"`
}
```

`json` и другие пакеты читают tags через reflect. Парсинг tags вручную — редко; обычно stdlib или генератор.

---

## Стоимость и альтернативы

Reflect: аллокации, нет inline, обход через descriptor — **медленно** относительно прямого доступа.

| Задача | Предпочтительнее |
|--------|------------------|
| JSON API | struct tags + `encoding/json` |
| Свой формат, производительность | генерация кода, ручной marshal |
| Обобщённый контейнер | type parameters, не `reflect` |
| Сравнение struct | метод `Equal()`, не `DeepEqual` в цикле |

Кешировать `reflect.Type` в map, не вызывать `TypeOf` на каждой итерации.

`CanSet` / `CanInterface`: менять можно только addressable значения; unexported поля — не трогать (или `unsafe`, что не рекомендуется).

---

## На практике

- Не вызывать reflect в горячем пути без кеша `reflect.Type`.
- Сначала generics или явные типы; reflect — только если тип неизвестен при компиляции.
