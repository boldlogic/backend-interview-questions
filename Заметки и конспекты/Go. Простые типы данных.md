# Go. Простые типы данных

## Строки (string)

### Неизменяемы

### Являются структурой, содержащей:

- Указатель на массив байтов, который содержит фактические данные строки

- Длину строки

### Последовательность байтов, без требования к конкретной кодировке

- UTF-8 — наиболее распространённая кодировка для Unicode

- len() измеряет длину в байтах

- строки могут содержать символы, не входящие в таблицу ASCII и не умещающиеся в один байт

### Функции языка Go предполагают, что строки используют кодировку UTF-8

### Для работы с подстроками и кодовыми точками предпочтительно использовать пакеты strings и unicode/utf8

### Различие между len(str), utf8.RuneCountInString(str) и []rune(str)

- len(str) возвращает количество байтов

- utf8.RuneCountInString(str) считает кодовые точки Unicode

- []rune(str) создаёт срез рун

## byte

### Синоним uint8. Они полностью идентичны и могут использоваться взаимозаменяемо

### Используется для работы со строками и байтовыми массивами

### Может хранить только значения от 0 до 255

### Подходит для работы с ASCII и UTF-8

### Поддерживает побитовые операции

## Специальные типы

### nil

- Специальное значение для указателей, срезов, карт, функций, каналов и интерфейсов

### error

- Встроенный интерфейс для представления ошибок

	- errors.New(), fmt.Errorf(), errors.Is()

### chan T

- Канал для обмена данными между горутинами

## rune (uint32)

### занимает 4 байта

### может представлять любой символ из набора Unicode.

### Используется для работы с отдельными символами (поиск, сравнение, замена)

### Как получить символ из строки? — []rune(str)[i]

## Целочисленные типы

### Знаковые

- int

	- Размер зависит от архитектуры (32/64 бита)

- int8

	- От –128 до 127

- int16

	- От –32 768 до 32 767

- int32

	- От –2 147 483 648 до 2 147 483 647

- int64

	- От –9 223 372 036 854 775 808 до 9 223 372 036 854 775 807

- Для работы с большими числами используется big.Int из пакета math/big

### Беззнаковые

- uint8

	- От 0 до 255

- uint16

	- От 0 до 65 535

- uint32

	- От 0 до 4 294 967 295

- uint64

	- От 0 до 18 446 744 073 709 551 615

-  uint

	- Размер зависит от архитектуры (32/64 бита)

### Ноль типа int — не то же самое, что ноль типа int32.

### uintptr

- целое число без знака

- Используется для хранения адресов памяти и других числовых значений

- Размер зависит от архитектуры (обычно 4 или 8 байт)
