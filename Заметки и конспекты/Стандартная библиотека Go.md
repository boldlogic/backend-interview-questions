
Стандартная библиотека Go — это множество встроенных пакетов, которые содержат готовые инструменты для решения распространённых задач в разработке.

Вот некоторые из пакетов, без которых вы, скорее всего, не обойдётесь:

- [fmt](https://pkg.go.dev/fmt) — реализует форматированный ввод-вывод.
    
- [strings](https://pkg.go.dev/strings) — реализует простые функции для обработки строк в кодировке UTF-8.
    
- [os](https://pkg.go.dev/os) — позволяет взаимодействовать с операционной системой.
    
- [errors](https://pkg.go.dev/errors) — реализует функции для обработки ошибок.
    
- [strconv](https://pkg.go.dev/strconv) — позволяет преобразовывать базовые типы данных в строковые и обратно.
    
- [log](https://pkg.go.dev/log) — реализует простое логирование.
    
- [math](https://pkg.go.dev/math) — предоставляет базовые константы и математические функции.
    
- [flag](https://pkg.go.dev/flag) — реализует синтаксический анализ флагов командной строки.
    
- [bytes](https://pkg.go.dev/bytes) — реализует функции для манипулирования фрагментами байтов. Аналогично возможностям пакета `strings`.
    
- [bufio](https://pkg.go.dev/bufio) — реализует буферизованный ввод-вывод.
    
- [context](https://pkg.go.dev/context) — определяет тип `Context`, который переносит крайние сроки, сигналы отмены и другие значения, определяемые запросом, через границы API и между процессами.
    
- [encoding/json](https://pkg.go.dev/encoding/json) — реализует кодирование и декодирование JSON.
    
- [net/http](https://pkg.go.dev/net/http) — предоставляет клиентскую и серверную реализации HTTP.
    
- [path](https://pkg.go.dev/path) — реализует служебные процедуры для манипулирования путями, разделёнными косой чертой.
    
- [sync](https://pkg.go.dev/sync) — предоставляет базовые примитивы синхронизации, такие как блокировки взаимного исключения.
    
- [testing](https://pkg.go.dev/testing) — обеспечивает поддержку тестирования пакетов Go. Он используется совместно с командой `go test`.
    
- [time](https://pkg.go.dev/time) — предоставляет возможность измерения и отображения даты и времени.
    

Это лишь часть всех доступных модулей. Полный их перечень можно найти в [официальной документации](https://pkg.go.dev/std).
