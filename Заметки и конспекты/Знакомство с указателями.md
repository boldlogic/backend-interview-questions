Каждый день вы сталкиваетесь с указателями:

- рекламный баннер на улице показывает, что до любимой кафешки осталось 100 метров прямо и 50 направо;
- ссылка веб-страницы говорит пользователю, куда он перейдёт, кликнув по ней мышкой;
- реклама магазина сообщает адрес, куда можно прийти за покупками;
- карточка библиотечного каталога указывает на номер шкафа и полки, где стоит книга.

Во всех этих случаях чтобы увидеть физический объект, нужно последовать за указаниями. В языке Go для работы с переменными тоже используют указатели, и работают они по схожему принципу.

## Что такое указатель в Go

Книга в шкафу занимает часть пространства. Точно так же и с переменными в Go: каждая переменная в программе занимает кусок памяти. В случае с книгой — чем она толще, тем больше места займёт. Вот здесь ситуация с переменными другая: объём занимаемой памяти зависит не от значения переменной, а от её типа. Например, под переменную типа `int32` будет зарезервировано 4 байта, и не важно, равна она нулю или миллиарду. Переменная типа `int64` займёт 8 байт, а переменная типа `bool` — 1 байт. **Указатель** определяет местоположение в памяти, где хранится значение переменной. Другими словами, указатель содержит её адрес. При желании по этому адресу можно перейти и получить нужные данные.

---
## Как получить адрес переменной

Чтобы получить адрес переменной, перед ней необходимо указать оператор `&`. Посмотрите на примере — запустите код ниже.

`package main`
`import "fmt"`
`func main() {`
    `var i, j int64`
    `var n int32`
    `b := true`
    `pi := 3.1415`
    `fmt.Println(&i, &j, &n, &b, &pi)`
`}`

---
По умолчанию адреса выводятся в шестнадцатеричном виде, поэтому при запуске кода выше получится примерно такой результат: `0xc0000a2000 0xc0000a2008 0xc0000a2010 0xc0000a2014 0xc0000a2018`. Обратите внимание: на вашем компьютере результат будет похож, но не идентичен. Каждый при запуске этого кода получит разные результаты. Более того, при повторных запусках на одном и том же компьютере результаты, скорее всего, тоже будут отличаться. Дело в том, что оперативная память постоянно занимается и освобождается и невозможно запросить под свои нужды куски памяти с определёнными адресами.

## Как объявить указатель в коде

В предыдущем примере через оператор `&` были получены и выведены адреса переменных. Чтобы получить указатели, нужно эти адреса сохранить. Есть несколько способов, как это можно сделать.

Способ первый, самый простой — использовать оператор присваивания `:=`. В этом случае сразу будет создана переменная-указатель и ей будет присвоен указанный адрес.

```
i := 10
ptr := &i  // ptr — указатель на переменную i 
```

Второй способ — объявить переменную-указатель через ключевое слово `var` и затем присвоить ей нужный адрес. В языке Go требуется указывать, на какой тип переменных может ссылаться указатель. Для этого используют оператор `*`: `var <имя> *<тип>`, например, `var p *string`.

```
var ptr *int
var i int

// указатель ptr будет указывать на переменную i
ptr = &i 
```

Если попытаться присвоить указателю адрес переменной другого типа, компилятор выдаст ошибку.

```
var ptr *int
var i int32
// в строке ниже будет ошибка компиляции
// cannot use &i (value of type *int32) as *int value in assignment
ptr = &i 
```

Третий способ создать указатель — через встроенную функцию `new(<тип>)`. В её параметре нужно указать тип для создания неименованной переменной — под неё будет зарезервирован участок памяти соответствующего размера, а сама переменная будет инициализирована нулевым значением. Функция возвращает указатель на созданную переменную. Этот способ удобен, когда вы не хотите определять переменную, а намерены сразу работать с указателями.

```
ptr1 := new(map[string]string) // указатель на мапу
ptr2 := new(string)            // указатель на строку
ptr3 := new(MyType)            // указатель на структуру MyType 
```

Указатели могут ссылаться на переменные любых типов, в том числе, на мапы, слайсы, структуры и т.п.

## Нулевое значение указателя: nil

В примерах выше вы уже видели, что можно определить переменную-указатель, но не присваивать ей адрес в качестве значения. Например, при определении `var ptr *int` адрес переменной-указателю пока не присвоен. Нулевое значение любого указателя равно `nil`. `nil` — это специальный предопределённый идентификатор, у него нет типа.

Указатель с нулевым значением ещё называют «пустым». Ровно так же, в библиотечной картотеке могут быть пустые карточки для книг: они есть, но пока не заполнены.

Если, например, в параметре функции получен указатель и нет уверенности, что он на что-то ссылается, то следует сравнить его с `nil` прежде чем пытаться получить его значение. Это поможет избежать ошибки: если попытаться взять значение от пустого указателя, возникнет паника `runtime error: invalid memory address or nil pointer dereference`.

```
var ptr *int

// ...
if ptr != nil {
    // указатель ptr не пустой и можно с ним работать
    // ...
} 
```

Вы уже сталкивались с такими проверками, когда знакомились с ошибками в Go. Тип `error` — это указатель на специальную структуру. Когда он равен `nil` — ошибки нет. В противном случае, переменная типа `error` содержит адрес, где хранится информация об ошибке.

Указатели можно сравнивать не только с `nil`, но и друг с другом. Два указателя равны, когда они указывают на одну и ту же переменную или когда оба равны `nil`.

```
var p1, p2 *string

fmt.Println( p1 == p2 ) // выведет true
s := "Сравниваем указатели"
p1 = &s
p2 = &s
fmt.Println( p1 == p2 ) // также выведет true 
```

Указатели одинакового типа можно присваивать друг другу. Например, не обойтись только одним указателем при работе с графами, деревьями и другими сложными структурами данных.

Любому указателю можно присвоить его нулевое значение `nil`. И тогда, если этот указатель больше нигде не используется, сборщик мусора очистит область памяти, на которую он ссылался. Программа станет работать быстрее, а дышать станет свободней!

## В чём польза указателей

Представьте, что функция должна преобразовать цветное изображение в чёрно-белое. Чем больше размеры картинки, тем больше памяти требуется для её хранения. Функция должна получить всё изображение целиком и возвратить преобразованные данные. Без указателей содержимое картинки придётся скопировать, передать копию в функцию, а затем — обратно, чтобы получить результат. Всё это будет занимать дополнительное время. Это время можно сэкономить — передать в функцию не копию изображения, а указатель на само изображение. На 64-битных ОС указатель занимает 64 бита (8 байт), и передать его в функцию можно так же быстро, как обычное число. То есть можно получить адрес данных, передать указатель в функцию и там внести изменения. При этом даже не нужно ничего возвращать — все действия будут происходить не с копией, а с оригинальными данными.

![](https://code.s3.yandex.net/go/go1F/28.%D0%97%D0%BD%D0%B0%D0%BA%D0%BE%D0%BC%D1%81%D1%82%D0%B2%D0%BE_%D1%81_%D1%83%D0%BA%D0%B0%D0%B7%D0%B0%D1%82%D0%B5%D0%BB%D1%8F%D0%BC%D0%B8.%D0%98%D0%B7%D0%BE%D0%B1%D1%80%D0%B0%D0%B6%D0%B5%D0%BD%D0%B8%D0%B5.png)

Указатели используются в уже знакомых вам мапах и слайсах, именно поэтому вы можете менять значения их элементов внутри функций.

Итак, вот в каких случаях эффективны указатели:

**Работа с большими объёмами данных.** Указатели позволяют использовать большой объём данных (например, передать их в функцию или присвоить их переменной), но при этом не копировать их. Вместо самих данных можно использовать указатель на них. Это значительно повышает производительность программы. **Динамическое выделение памяти.** Функция `new()` позволяет динамически выделять память во время выполнения программы. Это особенно полезно, когда точный размер или количество создаваемых структур данных неизвестны. **Передача параметров по указателю.** Передавая переменные в функцию по указателю, можно изменять их значения внутри функции. **Работа с большими структурами данных.** Указатели позволяют эффективно работать со сложными структурами данных — например, со списками, деревьями или графами.

## Указатели на структуры

Предположим, что имеется структура и нужно, чтобы в методе изменялись значения её полей. В этом случае, объект метода следует определить как указатель на структуру: `func (obj *StructName) MethodName(...)`. Если указывать только имя структуры, то в метод будет передаваться копия объекта и изменение полей не коснётся оригинальных данных. Если в метод передаётся указатель на объект, то изменения полей будут относится к самому объекту, а не его копии.
```
type Hero struct {
    Name string // имя героя
    Health int // здоровье
    // ...
}

// Damage уменьшает уровень жизни на указанное значение.
// Возвращает true при положительном уровне и false при отрицательном. 
func (hero *Hero) Damage(damage int) bool {
    hero.Health -= damage
    return hero.Health > 0
} 
```

При вызове такого метода можно указать как саму переменную структуры, так и указатель на неё. В обоих вариантах будет передаваться указатель.
```
var hero Hero
hero.Health = 100
// указываем структуру, но передаётся указатель
hero.Damage(10)  
// можно явно передать адрес на структуру
(&hero).Damage(15)
// определяем указатель
phero := &hero
// передаём указатель на структуру
phero.Damage(20)         
fmt.Println(hero.Health) // выведет 55 
```

Получается, если в существующем методе вдруг понадобится изменять поля структуры, то достаточно добавить `*` перед именем структуры и не требуется вносить изменения в вызовы метода.

Также можно сразу инициализировать структуру и получить указатель на неё.
```
hero := &Hero{Health: 100}
hero.Damage(10)          // передаём указатель 
```

## Что в итоге

Указатель — это переменная, в которой хранится адрес объекта.

Объявить переменную-указатель можно тремя способами: присвоить переменной адрес, полученный через оператор `&`; объявить указатель через ключевое слово `var`, указав его тип; воспользоваться встроенной функцией `new()`.

Указатели могут быть разных типов, в зависимости от типа данных, на которые ссылаются. При определении указателя перед именем типа ставят `*`.

Указатель, который ни на что не указывает, равен `nil`. Это нулевое значение для указателей. Попытка взять значение у «пустого» указателя приведёт к панике.

Указатели позволяют избежать копирования данных, просто передавая ссылку на них. Это удобно в работе с большими данными — программа работает быстрее и эффективней.

С указателями может быть непросто: их сложно понять и они могут быть причиной ошибок. Но преодоление этих трудностей того стоит, поверьте! Грамотная работа с указателями может в разы повысить производительность программы, уменьшить расход памяти и дать больше гибкости при работе с данными.

# Разыменование указателей

Вы уже знаете, что указатель содержит адрес на область памяти, но не само значение объекта. А можно ли из указателя получить значение? Да, и это значение можно не только получить, но ещё и поменять. Для этого в Go есть оператор `*`, а сама операция называется «разыменование указателя».

## Получение значений

Понятней сразу объяснить на примере. Вот фрагмент кода:

```
var i = 123
ptr := &i 
```

А вот как применить операцию разыменования и получить значение переменной `i` по её указателю `ptr`:

```
var i = 123
ptr := &i
j := *ptr      // j имеет тип int
fmt.Println(j) // выведет 123 
```

Обратите внимание: разыменовывание возвращает значение соответствующего типа:

- указатель типа `*int` вернёт результат `int`;
- указатель типа `*[]string` вернёт `[]string` и так далее.

Оператор `*` нужен не всегда. При обращении к полям структуры, на которую ссылается указатель, разыменование происходит автоматически. Оператор `*` в такой ситуации можно использовать, но это не обязательно.

```
ptrHero := &Hero{
    Health: 100,
}

fmt.Println(ptrHero.Health)
// можно и так
// fmt.Println((*ptrHero).Health)
// оба варианта выведут 100 
```
