# Книги → Markdown (очищенные)

Исходники с разбивкой по страницам: [`_raw_pages/`](_raw_pages/).

**Убрано при очистке:**
- заголовки `## Страница N`
- поле `Страниц: N` в шапке
- повторяющиеся колонтитулы (название книги / copyright на каждой странице)
- голые номера страниц
- блоки оглавления (строки с отточиями и номерами)

**Сохранено:** основной текст, `#` название, строка `Источник:`.

Сканы без текстового слоя по-прежнему почти пустые (нужен OCR).
