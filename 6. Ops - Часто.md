## Как убить процесс в Linux?
**Частота:** 9/86
**Темы:** #ops #linux #devops
- [ ] Скорректировано
- [ ] последний повтор
kill `<pid>` — послать сигнал (по умолчанию SIGTERM, 15): процесс может корректно завершиться. 
kill -9 `<pid>/kill -KILL`— SIGKILL: немедленное убийство без обработки. Сначала пробуют TERM, -9 — когда процесс не реагирует.

**Подробности:**
- `kill -l`— список сигналов.
- Ctrl+C отправляет в программу SIGINT.
- Сигналы UNIX — программные прерывания; безопаснее называть по имени, не только по номеру.
- В контейнере/K8s — ещё `kubectl delete pod`, stop grace period.
- `kill` с `killall`/`pkill`(по имени, не по pid).

## Docker vs виртуальная машина
**Частота:** 9/86
**Темы:** #ops #linux #devops
- [ ] Скорректировано
- [x] последний повтор ✅ 2026-07-04

Контейнер — изоляция через **namespaces** и **cgroups** на **общем ядре** хоста; образ — слои ФС + зависимости приложения. VM — полная виртуализация/паравиртуализация: своё гостевое ядро, больше overhead на CPU/RAM/диск, сильнее изоляция.


- containerd/CRI — runtime под K8s.
- VM уместны при жёсткой изоляции, другой ОС, legacy.

## Что такое Pod в Kubernetes?
**Частота:** 8/86
**Темы:** #ops #linux #devops
- [ ] Скорректировано
- [ ] последний повтор

Pod — минимальная единица деплоя в Kubernetes: один или несколько контейнеров с общим network namespace (один IP), volumes и (опционально) IPC. Контейнеры в Pod делят localhost и могут общаться через loopback.


- Lifecycle: Pending → Running → Succeeded/Failed.
- Restart policy на уровне Pod.

## Что происходит при malloc / выделение 1 KB?
**Частота:** 4/86
**Темы:** #ops #linux #devops #go/memory
- [ ] Скорректировано
- [x] последний повтор ✅ 2026-07-04


Runtime/аллокатор (в Go —`mallocgc` в runtime) берёт память из уже зарезервированных арен heap или запрашивает у ОС через `mmap`/brk. ОС может выделить виртуальную память лениво (страницы подставляются при первом обращении). Возвращается указатель на участок; при нехватке —.
