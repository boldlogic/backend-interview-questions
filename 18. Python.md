### GIL в Python
**Частота:** 6/117
**Темы:** #python #concurrency

**Эталон на собесе:**
**GIL (Global Interpreter Lock)** — в CPython один поток исполняет bytecode в момент времени → CPU-bound многопоточность почти не ускоряется.
- **I/O-bound** — threading/asyncio ок (GIL отпускается на I/O).
- **CPU-bound** — multiprocessing / ProcessPoolExecutor (отдельные интерпретаторы) или нативный код (numpy/C).
- Не путать с «Python однопоточный»: потоки есть, но не для параллельного CPU bytecode.
